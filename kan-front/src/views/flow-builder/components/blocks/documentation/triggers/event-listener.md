# Event Listener

## Что это

Запуск потока при событии в системе (создана задача, обновлена доска, новый пользователь).

## Зачем нужен

- Автоматизация при изменениях в системе
- Реакция на действия пользователей
- Синхронизация данных
- Уведомления о важных событиях

## Поля

### Event Type

Какое событие слушать

**Примеры:**

- `task.created` - создана задача
- `task.updated` - задача обновлена
- `task.status_changed` - изменён статус
- `board.created` - создана доска
- `user.registered` - новый пользователь

### Event Filter

Фильтр событий (опционально)

Слушать только определённые события

**Примеры:**

- Только задачи с приоритетом "High"
- Только статус → "Done"
- Только определённая доска

Формат: JSON условие

```json
{
  "priority": "high",
  "assignedTo": "user123"
}
```

### Debounce Time

Задержка перед запуском (миллисекунды)

Если событие происходит много раз подряд - запустить только один раз после паузы

**Пример:**

- Debounce 2000ms
- Задача обновилась 5 раз за 1 секунду
- Поток запустится один раз через 2 секунды после последнего обновления

### Save Event Data to Variable

Имя переменной для данных события

Пример: `event` → доступно как `{event.task}`, `{event.user}`

## Примеры использования

### Новая задача → назначить ответственного

```
Event: task.created
Filter: {"assignedTo": null}
→ AI выбирает ответственного по описанию
→ Назначает задачу
→ Отправляет уведомление
```

### Задача завершена → создать отчёт

```
Event: task.status_changed
Filter: {"newStatus": "done"}
→ Собрать информацию о задаче
→ Обновить статистику
→ Если это последняя задача проекта - создать итоговый отчёт
```

### Новый пользователь → приветствие

```
Event: user.registered
→ Отправить welcome email
→ Создать onboarding задачи
→ Добавить в Slack канал
```

### Обновление задачи → синхронизация с Jira

```
Event: task.updated
Debounce: 5000ms (чтобы не спамить при частых правках)
→ Отправить изменения в Jira API
```

### Комментарий → уведомление

```
Event: task.commented
Filter: {"mentions": "{current_user.id}"}
→ Отправить push уведомление
→ Email если пользователь оффлайн
```
