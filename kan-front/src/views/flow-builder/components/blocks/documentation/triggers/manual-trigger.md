# Manual Trigger

## Что это

Ручной запуск потока пользователем (кнопка в интерфейсе).

## Зачем нужен

- Действия по требованию
- Тестирование потоков
- Разовые операции
- Кнопки для пользователей

## Поля

### Trigger Name

Название кнопки/действия

**Примеры:**

- "Сгенерировать отчёт"
- "Синхронизировать с Jira"
- "Отправить напоминания"

### Description

Описание что делает поток

Показывается пользователю перед запуском

### Input Parameters

Параметры которые нужно ввести при запуске

**Примеры:**

- Дата начала и конца (для отчёта)
- ID пользователя
- Текст сообщения

Формат: массив полей

```json
[
  {
    "name": "startDate",
    "type": "date",
    "label": "Дата начала",
    "required": true
  },
  {
    "name": "userId",
    "type": "text",
    "label": "ID пользователя"
  }
]
```

### Show Confirmation

Показать подтверждение перед запуском?

Полезно для важных операций (удаление, отправка)

### Available For

Кто может запускать

**Опции:**

- **All Users** - все пользователи
- **Admins Only** - только админы
- **Specific Users** - определённые пользователи
- **Specific Roles** - определённые роли

## Примеры использования

### Создать еженедельный отчёт

```
Button: "Сгенерировать отчёт"
Parameters:
  - Дата начала
  - Дата конца
  - Email получателя
→ Собрать данные за период
→ Создать PDF отчёт
→ Отправить на email
```

### Синхронизация с Jira

```
Button: "Синхронизировать Jira"
Confirmation: true
→ Получить все задачи из Jira
→ Создать/обновить задачи в системе
→ Показать результат
```

### Массовое обновление задач

```
Button: "Обновить приоритеты"
Available For: Admins Only
Parameters:
  - Новый приоритет
  - Фильтр задач (опционально)
→ Найти задачи
→ Обновить приоритет
→ Уведомить ответственных
```

### Отправить рассылку

```
Button: "Отправить уведомления"
Parameters:
  - Текст сообщения
  - Целевая группа (все/активные/неактивные)
Confirmation: true
→ Выбрать получателей
→ Отправить сообщения
→ Показать статистику
```

### Экспорт данных

```
Button: "Экспортировать данные"
Parameters:
  - Формат (CSV/Excel/JSON)
  - Что экспортировать (задачи/пользователи/доски)
→ Собрать данные
→ Создать файл
→ Отдать на скачивание
```
