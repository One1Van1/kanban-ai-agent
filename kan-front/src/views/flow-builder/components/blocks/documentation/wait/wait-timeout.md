# Wait Timeout - Пауза на время

## Описание

Приостанавливает выполнение потока на заданное время.

## Категория

**Wait** (Ожидание)

## Конфигурация

### Поля

- **Duration** (`duration`) - Длительность паузы (число)
- **Unit** (`unit`) - Единица измерения времени:
  - `seconds` - Секунды
  - `minutes` - Минуты
  - `hours` - Часы

### Variable Storage

❌ **Не поддерживает сохранение в переменную** (блок управления временем)

## Пример использования

**Сценарий 1:** Пауза перед повторной попыткой

```json
{
  "duration": 30,
  "unit": "seconds"
}
```

**Сценарий 2:** Отложить уведомление на час

```json
{
  "duration": 1,
  "unit": "hours"
}
```

## Использование в потоке

```
[API Call] → [Wait Timeout: 5 минут] → [Check Status] → [If/Else]
                                                            ├─ Success → [Done]
                                                            └─ Failed → [Wait Timeout] (retry)
```

## Примечания

- Используйте для задержек между действиями
- Полезно для rate limiting API запросов
- Можно использовать в циклах для периодических проверок
- Не блокирует другие потоки
