# Comment - Комментарий

## Описание

Добавляет текстовый комментарий или заметку в поток. Полезно для документирования логики и оставления пометок.

## Категория

**Actions** (Действия)

## Конфигурация

### Поля

- **Comment Text** (`commentText`) - Текст комментария или заметки

### Variable Storage

❌ **Не поддерживает сохранение в переменную** (информационный блок)

## Пример использования

**Сценарий:** Добавить пояснение к сложной логике

```json
{
  "commentText": "Этот блок проверяет статус задачи и отправляет уведомление только для важных задач с высоким приоритетом"
}
```

## Использование в потоке

```
[Trigger] → [Comment: "Начало обработки задач"] → [Loop] → [If/Else]
```

## Примечания

- Не выполняет никаких действий, только документация
- Отображается в визуализации потока
- Помогает командам понимать логику потока
- Можно использовать для TODO заметок
