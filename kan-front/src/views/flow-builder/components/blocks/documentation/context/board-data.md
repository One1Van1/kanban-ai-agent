# Board Data

## Что это

Получить данные о досках (канбан досках в системе).

## Зачем нужен

- Работа с несколькими досками
- Статистика по доскам
- Поиск досок по критериям
- Получить список всех досок проекта

## Поля

### Operation

Что делать

**Get Board by ID** - Получить конкретную доску

- Нужно знать ID доски

**Get All Boards** - Все доски пользователя/команды

**Search Boards** - Найти доски по условию

- По названию, тегам, дате создания

### Board ID

ID доски (для Get Board by ID)

Можно использовать переменную: `{task.boardId}`

### Filters

Фильтры для поиска (для Search Boards)

**Примеры:**

- По названию: `{"name": "Marketing"}`
- По создателю: `{"createdBy": "user123"}`
- По дате: `{"createdAfter": "2024-01-01"}`

### Include

Что включить в ответ

- **Tasks** - задачи доски
- **Members** - участники
- **Stats** - статистика

### Save Result to Variable

Имя переменной для данных

Пример: `boards` → `{boards[0].name}`, `{boards.length}`

## Примеры использования

### Отчёт по всем доскам

```
Board Data: Get All Boards
  Include: Stats
→ Собрать статистику по каждой доске
→ Создать сводный отчёт
→ Отправить руководителю
```

### Найти неактивные доски

```
Board Data: Search Boards
  Filters: {"lastActivityBefore": "30 days ago"}
→ Отправить уведомление владельцам
→ Предложить архивировать
```

### Копировать задачи между досками

```
Board Data: Get Board by ID {sourceBoard}
  Include: Tasks
→ Для каждой задачи:
  → Создать копию на другой доске
```

### Синхронизация прав доступа

```
Board Data: Get All Boards
  Include: Members
→ Проверить права участников
→ Синхронизировать с корпоративной системой
```

### Статистика команды

```
Board Data: Search Boards
  Filters: {"team": "development"}
  Include: Tasks, Stats
→ Посчитать:
  - Сколько задач в работе
  - Среднее время выполнения
  - Загрузка команды
```
