# Condition

## Что это

Условие if/else - выполнить разные действия в зависимости от условия.

## Зачем нужен

- Проверка условий
- Разветвление логики
- Принятие решений в потоке

## Поля

### Condition Expression

Условие для проверки

JavaScript выражение которое возвращает `true` или `false`

**Примеры:**

```javascript
{task.priority} === "high"
{user.role} === "admin"
{tasks.length} > 10
{order.total} >= 1000
{task.dueDate} < {now}
```

**Операторы:**

- `===` - равно
- `!==` - не равно
- `>`, `<`, `>=`, `<=` - сравнение
- `&&` - и
- `||` - или
- `!` - не

### THEN Branch

Что выполнить если условие `true`

Блоки которые запустятся если условие верно

### ELSE Branch (опционально)

Что выполнить если условие `false`

Блоки если условие неверно

## Примеры использования

### Проверка приоритета

```
Condition: {task.priority} === "high"
THEN:
  → Назначить старшему специалисту
  → Отправить срочное уведомление
ELSE:
  → Назначить свободному специалисту
```

### Проверка роли пользователя

```
Condition: {user.role} === "admin"
THEN:
  → Выполнить административное действие
ELSE:
  → Отправить "Недостаточно прав"
```

### Просроченная задача

```
Condition: {task.dueDate} < {now} && {task.status} !== "done"
THEN:
  → Отправить напоминание
  → Изменить приоритет на "high"
  → Уведомить руководителя
ELSE:
  → Ничего не делать
```

### Большой заказ

```
Condition: {order.total} >= 10000
THEN:
  → Применить скидку 10%
  → Назначить персонального менеджера
  → Отправить благодарственное письмо
ELSE:
  → Стандартная обработка
```

### Новый пользователь

```
Condition: {user.tasksCompleted} === 0
THEN:
  → Отправить welcome tutorial
  → Создать onboarding задачи
ELSE:
  → Обычное приветствие
```

### Несколько условий

```
Condition: {task.priority} === "high" && {task.assignedTo} === null
THEN:
  → Срочно назначить ответственного
  → Эскалация руководителю

Condition: {task.status} === "done" && {task.hasSubtasks}
THEN:
  → Проверить все ли подзадачи выполнены
```
