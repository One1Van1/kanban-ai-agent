# 🤖 AI Агент анализа выполненных задач по стрижкам

## ✅ Создано успешно!

AI агент для анализа выполненных задач по стрижкам создан и готов к работе в папке `ai-reporting-agent`.

## 📋 Что создано:

### 🏗️ Структура модуля:

```
src/ai-reporting-agent/
├── ai-reporting-agent.module.ts          # Основной модуль
└── analyze-completed-haircut-tasks/      # Эндпоинт для анализа задач
    ├── analyze-completed-haircut-tasks.controller.ts    # REST контроллер
    ├── analyze-completed-haircut-tasks.service.ts       # Бизнес-логика
    ├── analyze-completed-haircut-tasks.interface.ts     # Интерфейсы и типы
    ├── analyze-completed-haircut-tasks.dto.ts           # DTO для валидации
    ├── analyze-completed-haircut-tasks.module.ts        # Модуль эндпоинта
    └── analyze-completed-haircut-tasks.spec.ts          # Тесты
```

### 🚀 API Эндпоинты:

1. **POST** `/ai-reporting/analyze-completed-haircut-tasks/analyze`
   - Прямой анализ задачи по переданным данным

2. **GET** `/ai-reporting/analyze-completed-haircut-tasks/analyze/:issueKey`
   - Анализ задачи из Jira по ключу

3. **POST** `/ai-reporting/analyze-completed-haircut-tasks/webhook`
   - Webhook для автоматического анализа при изменении задач

4. **POST** `/ai-reporting/analyze-completed-haircut-tasks/employee-response`
   - Обработка ответов сотрудников на вопросы агента

### 🧠 Возможности агента:

✅ **Анализ времени выполнения:**

- Проверка соответствия нормативам по категориям
- Быстрая стрижка: 20-30 мин
- Обычная стрижка: 30-60 мин
- Креативная стрижка: 90+ мин

✅ **Расчёт стоимости:**

- Базовые цены: 400₽ / 800₽ / 1500₽
- Автоматическое применение скидки 10% для постоянных клиентов

✅ **Умный анализ объяснений:**

- Распознаёт объяснения превышения времени
- Определяет смену категории в процессе работы
- Задаёт уточняющие вопросы при необходимости

✅ **Интеграция с Jira:**

- Работает через webhook
- Добавляет комментарии с отчётами
- Перемещает задачи между колонками

## 🔧 Как использовать:

### 1. Запуск сервера:

```bash
yarn start:dev
```

### 2. Тестирование через Swagger:

- Откройте `http://localhost:3000/api`
- Найдите секцию `ai-reporting-agent`
- Протестируйте эндпоинты

### 3. Настройка webhook в Jira:

- URL: `{your-domain}/ai-reporting/analyze-completed-haircut-tasks/webhook`
- События: перемещение в колонку "Review"

## 📊 Примеры работы:

### Успешная задача в срок:

**Вход:**

### Превышение с объяснением:

**Вход:**

### Смена категории:

- Время: 95 мин

- 🔄 Категория обновлена на "Креативная"
- 💰 Цена: 1500₽
- 🏁 Автоматически в "Done"
