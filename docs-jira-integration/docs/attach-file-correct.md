# attach-file-correct

## Описание

Этот файл отвечает за прикрепление файлов к задачам в Jira.

## Действия

- Загружает файл из указанного пути
- Прикрепляет файл к задаче через Jira API
- Проверяет существование файла перед загрузкой
- Использует FormData для передачи файла
- Возвращает информацию о прикрепленном файле

## API

`POST /jira/attach-file/:taskKey`

## Входные данные

- taskKey: ключ задачи в Jira
- filePath: путь к файлу для прикрепления

## Результат

- Успешность операции
- Информация о прикрепленном файле
- Размер и тип файла
