# health-check-correct

## Описание

Этот файл отвечает за проверку работоспособности Jira интеграции.

## Действия

- Проверяет подключение к Jira API
- Тестирует аутентификацию
- Возвращает статус соединения
- Показывает версию Jira
- Логирует запросы health check

## API

`GET /jira/health`

## Входные данные

Нет входных параметров

## Результат

- Статус подключения к Jira
- Версия Jira API
- Время ответа
- Сообщение о состоянии
