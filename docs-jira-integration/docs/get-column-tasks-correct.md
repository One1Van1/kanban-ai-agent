# get-column-tasks-correct

## Описание

Этот файл отвечает за получение задач из определенной колонки канбан доски.

## Действия

- Формирует JQL запрос для поиска задач по статусу
- Получает задачи из указанной колонки (статуса)
- Фильтрует результаты по проекту
- Возвращает список задач с полной информацией
- Поддерживает пагинацию результатов

## API

`GET /jira/columns/:columnName/tasks`

## Входные данные

- columnName: название колонки (статуса)
- maxResults: максимальное количество результатов
- startAt: начальная позиция для пагинации

## Результат

- Список задач в колонке
- Общее количество найденных задач
- Информация о пагинации
