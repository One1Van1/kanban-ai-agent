# add-task-comment

## Описание

Этот файл отвечает за добавление комментариев к задачам в Jira.

## Действия

- Подключается к Jira API с аутентификацией
- Добавляет комментарий к указанной задаче
- Поддерживает форматирование текста
- Логирует успешное добавление комментария
- Обрабатывает ошибки API

## API

`POST /jira/tasks/:taskKey/comments`

## Входные данные

- taskKey: ключ задачи в Jira
- comment: текст комментария

## Результат

- Успешность операции
- ID добавленного комментария
- Сообщение о результате
