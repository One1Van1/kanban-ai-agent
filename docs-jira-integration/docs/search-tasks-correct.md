# search-tasks-correct

## Описание

Этот файл отвечает за поиск задач в Jira по различным критериям.

## Действия

- Выполняет JQL запросы для поиска задач
- Поддерживает сложные фильтры и условия
- Возвращает результаты с пагинацией
- Извлекает нужные поля задач
- Сортирует результаты поиска

## API

`POST /jira/search-tasks`

## Входные данные

- jql: JQL запрос для поиска
- startAt: начальная позиция
- maxResults: максимальное количество результатов
- fields: поля для извлечения

## Результат

- Список найденных задач
- Общее количество результатов
- Информация о пагинации
- Полные данные задач
