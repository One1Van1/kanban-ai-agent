# move-task-correct

## Описание

Этот файл отвечает за перемещение задач между статусами в Jira.

## Действия

- Получает доступные переходы для задачи
- Находит нужный переход по целевому статусу
- Выполняет переход задачи в новый статус
- Проверяет успешность перемещения
- Логирует операции перемещения

## API

`POST /jira/tasks/:taskKey/move`

## Входные данные

- taskKey: ключ задачи в Jira
- targetStatus: целевой статус для перемещения

## Результат

- Успешность операции
- Новый статус задачи
- ID выполненного перехода
- Сообщение о результате
