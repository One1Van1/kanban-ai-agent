# get-task-transitions-correct

## Описание

Этот файл отвечает за получение доступных переходов для задачи.

## Действия

- Получает список всех возможных переходов для задачи
- Показывает доступные статусы для перемещения
- Возвращает ID переходов для API
- Учитывает права пользователя на переходы
- Форматирует список переходов с описаниями

## API

`GET /jira/tasks/:taskKey/transitions`

## Входные данные

- taskKey: ключ задачи в Jira

## Результат

- Список доступных переходов
- ID и названия переходов
- Целевые статусы
- Описания переходов
