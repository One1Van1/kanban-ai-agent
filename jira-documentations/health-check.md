# Health Check API

## Описание

Эндпойнт для проверки состояния подключения к Jira API.

## Endpoint

```
GET /jira/health
```

## Описание функциональности

Проверяет доступность и корректность подключения к Jira API. Этот эндпойнт используется для мониторинга системы и диагностики проблем с подключением.

## Параметры запроса

Не требуются.

## Пример запроса

```bash
curl -X GET http://localhost:3000/jira/health
```

## Ответы

### Успешный ответ (200)

```json
{
  "status": "healthy",
  "timestamp": "2025-09-23T15:04:11.000Z"
}
```

### Структура ответа

| Поле      | Тип    | Описание                                       |
| --------- | ------ | ---------------------------------------------- |
| status    | string | Статус подключения ("healthy" или "unhealthy") |
| timestamp | string | Временная метка проверки в формате ISO         |

## Возможные ошибки

- **500 Internal Server Error** - Проблемы с подключением к Jira API
- **503 Service Unavailable** - Jira API недоступна

## Примечания

- Используется для мониторинга системы
- Рекомендуется вызывать регулярно для проверки состояния интеграции
- Не требует аутентификации пользователя, использует системные настройки подключения
