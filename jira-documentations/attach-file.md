# Attach File API

## Описание

Эндпойнт для прикрепления файлов к задачам в Jira.

## Endpoint

```
POST /jira/attach-file/{taskKey}
```

## Описание функциональности

Прикрепляет файл к указанной задаче в Jira по пути к файлу в файловой системе. Файл будет доступен для скачивания всем пользователям, имеющим доступ к задаче.

## Параметры запроса

### Path Parameters

| Параметр | Тип    | Обязательный | Описание           | Пример |
| -------- | ------ | ------------ | ------------------ | ------ |
| taskKey  | string | Да           | Ключ задачи в Jira | KAN-5  |

### Request Body

```json
{
  "filePath": "/path/to/file.png"
}
```

| Поле     | Тип    | Обязательный | Описание                               |
| -------- | ------ | ------------ | -------------------------------------- |
| filePath | string | Да           | Полный путь к файлу в файловой системе |

## Пример запроса

```bash
curl -X POST http://localhost:3000/jira/attach-file/KAN-5 \
  -H "Content-Type: application/json" \
  -d '{
    "filePath": "/Users/user/Documents/screenshot.png"
  }'
```

## Ответы

### Успешный ответ (200)

```json
{
  "success": true,
  "taskKey": "KAN-5",
  "fileName": "screenshot.png",
  "fileSize": 1024567,
  "attachmentId": "10456",
  "message": "File attached successfully",
  "timestamp": "2025-09-23T15:04:11.000Z"
}
```

### Структура ответа

| Поле         | Тип     | Описание                               |
| ------------ | ------- | -------------------------------------- |
| success      | boolean | Статус успешности операции             |
| taskKey      | string  | Ключ задачи, к которой прикреплён файл |
| fileName     | string  | Имя прикреплённого файла               |
| fileSize     | number  | Размер файла в байтах                  |
| attachmentId | string  | Уникальный ID вложения в Jira          |
| message      | string  | Сообщение о результате операции        |
| timestamp    | string  | Время прикрепления файла               |

## Возможные ошибки

### 400 Bad Request

```json
{
  "statusCode": 400,
  "message": "filePath must be provided",
  "error": "Bad Request"
}
```

### 404 Not Found (Файл)

```json
{
  "statusCode": 404,
  "message": "Файл не найден по указанному пути",
  "error": "File Not Found"
}
```

### 404 Not Found (Задача)

```json
{
  "statusCode": 404,
  "message": "Задача не найдена",
  "error": "Task Not Found"
}
```

### 403 Forbidden

```json
{
  "statusCode": 403,
  "message": "Недостаточно прав для прикрепления файлов",
  "error": "Forbidden"
}
```

### 413 Payload Too Large

```json
{
  "statusCode": 413,
  "message": "Файл превышает максимально допустимый размер",
  "error": "File Too Large"
}
```

### 415 Unsupported Media Type

```json
{
  "statusCode": 415,
  "message": "Тип файла не поддерживается",
  "error": "Unsupported File Type"
}
```

## Поддерживаемые типы файлов

- **Изображения**: .png, .jpg, .jpeg, .gif, .bmp, .svg
- **Документы**: .pdf, .doc, .docx, .xls, .xlsx, .ppt, .pptx
- **Текстовые файлы**: .txt, .md, .json, .xml, .csv
- **Архивы**: .zip, .rar, .7z, .tar.gz
- **Код**: .js, .ts, .py, .java, .cpp, .cs, .html, .css
- **Логи**: .log, .out, .err

## Ограничения

### Размер файлов

- Максимальный размер файла: **10 MB**
- Рекомендуемый размер: до **5 MB**

### Количество вложений

- Максимум вложений на задачу: **100 файлов**
- Общий размер всех вложений: **100 MB**

### Безопасность

- Исполняемые файлы (.exe, .bat, .sh) запрещены
- Скрипты (.ps1, .vbs) требуют дополнительных прав
- Файлы проходят антивирусную проверку

## Автоматизация

Этот эндпойнт может использоваться для автоматического прикрепления:

- Скриншотов при ошибках тестирования
- Логов при сбоях в production
- Отчётов из CI/CD пайплайнов
- Результатов анализа кода
- Диаграмм и схем

## Интеграция с файловой системой

- Поддерживаются абсолютные пути
- Поддерживаются относительные пути от корня проекта
- Автоматическое определение MIME-типа файла
- Сохранение оригинального имени файла

## Мониторинг и логирование

- Все операции прикрепления логируются
- Отслеживается размер и тип файлов
- Ведётся статистика использования
- Уведомления о превышении лимитов

## Права доступа

Для прикрепления файлов требуется:

- Доступ к проекту в Jira
- Права на просмотр и редактирование задачи
- Права на добавление вложений
- Доступ к файловой системе сервера

## Примечания

- Файлы копируются в Jira, оригинал остаётся на месте
- Изменения в оригинальном файле не влияют на вложение
- Удаление файла возможно только через интерфейс Jira
- Версионирование файлов не поддерживается (создается новое вложение)

## Альтернативные способы

Для загрузки файлов также можно использовать:

- Веб-интерфейс Jira
- Drag & Drop в комментариях
- Email-integration
- Mobile приложения Jira
