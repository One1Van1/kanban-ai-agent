# Get Task Transitions API

## Описание

Эндпойнт для получения списка доступных переходов (статусов) для конкретной задачи.

## Endpoint

```
GET /jira/tasks/{taskKey}/transitions
```

## Описание функциональности

Возвращает список всех возможных статусов, в которые можно переместить задачу из текущего состояния. Полезен для динамического построения интерфейсов и валидации переходов.

## Параметры запроса

### Path Parameters

| Параметр | Тип    | Обязательный | Описание           | Пример |
| -------- | ------ | ------------ | ------------------ | ------ |
| taskKey  | string | Да           | Ключ задачи в Jira | KAN-5  |

## Пример запроса

```bash
curl -X GET http://localhost:3000/jira/tasks/KAN-5/transitions
```

## Ответы

### Успешный ответ (200)

```json
[
  {
    "id": "2",
    "name": "backlog",
    "toStatusName": "backlog",
    "isAvailable": true
  },
  {
    "id": "11",
    "name": "To Questions",
    "toStatusName": "Questions",
    "isAvailable": true
  },
  {
    "id": "51",
    "name": "Done",
    "toStatusName": "Done",
    "isAvailable": true
  }
]
```

### Структура ответа

Массив объектов переходов:

| Поле         | Тип     | Описание                             |
| ------------ | ------- | ------------------------------------ |
| id           | string  | Уникальный ID перехода в Jira        |
| name         | string  | Название перехода (действия)         |
| toStatusName | string  | Название целевого статуса            |
| isAvailable  | boolean | Доступность перехода в данный момент |

## Возможные ошибки

### 404 Not Found

```json
{
  "statusCode": 404,
  "message": "Задача не найдена",
  "error": "Not Found"
}
```

### 400 Bad Request

```json
{
  "statusCode": 400,
  "message": "Некорректный формат ключа задачи",
  "error": "Bad Request"
}
```

### 500 Internal Server Error

```json
{
  "statusCode": 500,
  "message": "Ошибка при получении переходов",
  "error": "Internal Server Error"
}
```

## Использование

Этот эндпойнт особенно полезен для:

- Динамического построения UI для перемещения задач
- Валидации возможности перехода перед вызовом move-task
- Отображения доступных действий пользователю
- Автоматизации workflow

## Примеры типичных переходов

- **To Do → In Progress** - Начать работу
- **In Progress → Review** - Отправить на проверку
- **Review → Done** - Завершить задачу
- **Any Status → backlog** - Вернуть в бэклог

## Примечания

- Доступные переходы зависят от workflow проекта в Jira
- Переходы могут быть ограничены правами пользователя
- Список переходов динамический и может изменяться в зависимости от конфигурации Jira
- ID перехода используется для выполнения перемещения через move-task API
