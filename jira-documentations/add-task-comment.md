# Add Task Comment API

## Описание

Эндпойнт для добавления комментариев к задачам в Jira.

## Endpoint

```
POST /jira/tasks/{taskKey}/comment
```

## Описание функциональности

Добавляет текстовый комментарий к указанной задаче в Jira. Комментарий будет виден всем пользователям, имеющим доступ к задаче.

## Параметры запроса

### Path Parameters

| Параметр | Тип    | Обязательный | Описание           | Пример |
| -------- | ------ | ------------ | ------------------ | ------ |
| taskKey  | string | Да           | Ключ задачи в Jira | KAN-5  |

### Request Body

```json
{
  "comment": "Задача выполнена в соответствии с требованиями"
}
```

| Поле    | Тип    | Обязательный | Описание          |
| ------- | ------ | ------------ | ----------------- |
| comment | string | Да           | Текст комментария |

## Пример запроса

```bash
curl -X POST http://localhost:3000/jira/tasks/KAN-5/comment \
  -H "Content-Type: application/json" \
  -d '{
    "comment": "Задача выполнена в соответствии с требованиями. Все тесты прошли успешно."
  }'
```

## Ответы

### Успешный ответ (200)

```json
{
  "success": true,
  "taskKey": "KAN-5",
  "message": "Comment added successfully",
  "commentId": "10123",
  "timestamp": "2025-09-23T15:04:11.000Z"
}
```

### Структура ответа

| Поле      | Тип     | Описание                                    |
| --------- | ------- | ------------------------------------------- |
| success   | boolean | Статус успешности операции                  |
| taskKey   | string  | Ключ задачи, к которой добавлен комментарий |
| message   | string  | Сообщение о результате операции             |
| commentId | string  | Уникальный ID созданного комментария        |
| timestamp | string  | Время создания комментария                  |

## Возможные ошибки

### 400 Bad Request

```json
{
  "statusCode": 400,
  "message": "Комментарий не может быть пустым",
  "error": "Bad Request"
}
```

### 404 Not Found

```json
{
  "statusCode": 404,
  "message": "Задача не найдена",
  "error": "Not Found"
}
```

### 403 Forbidden

```json
{
  "statusCode": 403,
  "message": "Недостаточно прав для добавления комментария",
  "error": "Forbidden"
}
```

### 500 Internal Server Error

```json
{
  "statusCode": 500,
  "message": "Ошибка при добавлении комментария",
  "error": "Internal Server Error"
}
```

## Примеры использования

### Комментарий о выполнении

```json
{
  "comment": "Задача выполнена. Реализованы все требования из описания."
}
```

### Комментарий с технической информацией

```json
{
  "comment": "Добавлены новые методы API:\n- GET /api/users\n- POST /api/users\n- PUT /api/users/:id\n\nВсе эндпойнты покрыты тестами."
}
```

### Комментарий с упоминанием проблем

```json
{
  "comment": "Обнаружена проблема с валидацией email. Нужно дополнительное тестирование."
}
```

## Особенности

### Форматирование текста

Jira поддерживает различные форматы текста в комментариях:

- **Жирный текст**: `*жирный*`
- _Курсив_: `_курсив_`
- Код: `{{код}}`
- Ссылки: `[текст|URL]`

### Упоминания пользователей

Можно упоминать пользователей в комментариях:

```
[~username] - упоминание пользователя
```

### Специальные символы

- Переносы строк поддерживаются через `\n`
- Emoji и unicode символы поддерживаются
- HTML теги автоматически экранируются

## Использование

Этот эндпойнт полезен для:

- Документирования прогресса по задаче
- Коммуникации между участниками команды
- Фиксирования важных решений
- Отчётности о выполненной работе
- Автоматического логирования событий

## Интеграции

Комментарии могут быть добавлены автоматически:

- При изменении статуса задачи
- При выполнении CI/CD пайплайнов
- При интеграции с другими системами
- При срабатывании webhook'ов

## Права доступа

Для добавления комментариев требуется:

- Доступ к проекту в Jira
- Права на просмотр задачи
- Права на добавление комментариев
- Валидная аутентификация

## Примечания

- Комментарии нельзя удалить через этот API
- Все комментарии сохраняются в истории задачи
- Комментарии индексируются для поиска в Jira
- Уведомления о новых комментариях отправляются подписчикам задачи
