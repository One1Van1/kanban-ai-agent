# Get Task API

## Описание

Эндпойнт для получения подробной информации о конкретной задаче в Jira.

## Endpoint

```
GET /jira/tasks/{taskKey}
```

## Описание функциональности

Возвращает полную информацию о задаче по её ключу, включая название, описание, статус, исполнителя и другие поля.

## Параметры запроса

### Path Parameters

| Параметр | Тип    | Обязательный | Описание           | Пример |
| -------- | ------ | ------------ | ------------------ | ------ |
| taskKey  | string | Да           | Ключ задачи в Jira | KAN-5  |

## Пример запроса

```bash
curl -X GET http://localhost:3000/jira/tasks/KAN-5
```

## Ответы

### Успешный ответ (200)

```json
{
  "key": "KAN-5",
  "fields": {
    "summary": "Название задачи",
    "description": "Подробное описание задачи",
    "status": {
      "name": "Done",
      "id": "10001"
    },
    "assignee": {
      "displayName": "John Doe",
      "emailAddress": "john.doe@example.com"
    },
    "priority": {
      "name": "High",
      "id": "2"
    },
    "created": "2025-09-20T10:00:00.000Z",
    "updated": "2025-09-23T15:04:11.000Z"
  }
}
```

### Структура ответа

| Поле               | Тип    | Описание                   |
| ------------------ | ------ | -------------------------- |
| key                | string | Ключ задачи в Jira         |
| fields             | object | Объект с полями задачи     |
| fields.summary     | string | Название задачи            |
| fields.description | string | Описание задачи            |
| fields.status      | object | Статус задачи              |
| fields.assignee    | object | Исполнитель задачи         |
| fields.priority    | object | Приоритет задачи           |
| fields.created     | string | Дата создания              |
| fields.updated     | string | Дата последнего обновления |

## Возможные ошибки

- **404 Not Found** - Задача с указанным ключом не найдена
- **400 Bad Request** - Некорректный формат ключа задачи
- **500 Internal Server Error** - Ошибка при обращении к Jira API

## Примечания

- Ключ задачи должен соответствовать формату PROJECT-NUMBER (например: KAN-5)
- Возвращает только те поля, к которым у пользователя есть доступ
- Использует конфигурацию Jira API из переменных окружения
