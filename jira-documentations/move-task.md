# Move Task API

## Описание

Эндпойнт для перемещения задачи между колонками (статусами) в Jira.

## Endpoint

```
POST /jira/tasks/{taskKey}/move
```

## Описание функциональности

Перемещает задачу в указанный статус с возможностью добавления комментария к переходу. Автоматически определяет доступные переходы и выполняет необходимую операцию.

## Параметры запроса

### Path Parameters

| Параметр | Тип    | Обязательный | Описание           | Пример |
| -------- | ------ | ------------ | ------------------ | ------ |
| taskKey  | string | Да           | Ключ задачи в Jira | KAN-5  |

### Request Body

```json
{
  "targetStatus": "Done",
  "comment": "Задача завершена согласно требованиям"
}
```

| Поле         | Тип    | Обязательный | Описание                  | Возможные значения                                 |
| ------------ | ------ | ------------ | ------------------------- | -------------------------------------------------- |
| targetStatus | string | Да           | Название целевого статуса | New, backlog, Questions, In Progress, Review, Done |
| comment      | string | Нет          | Комментарий к перемещению | Любой текст                                        |

## Пример запроса

```bash
curl -X POST http://localhost:3000/jira/tasks/KAN-5/move \
  -H "Content-Type: application/json" \
  -d '{
    "targetStatus": "Done",
    "comment": "Задача завершена согласно требованиям"
  }'
```

## Ответы

### Успешный ответ (200)

```json
{
  "success": true,
  "taskKey": "KAN-5",
  "fromStatus": "In Progress",
  "toStatus": "Done",
  "transitionId": "51",
  "message": "Task moved successfully"
}
```

### Структура ответа

| Поле         | Тип     | Описание                    |
| ------------ | ------- | --------------------------- |
| success      | boolean | Статус успешности операции  |
| taskKey      | string  | Ключ перемещённой задачи    |
| fromStatus   | string  | Предыдущий статус задачи    |
| toStatus     | string  | Новый статус задачи         |
| transitionId | string  | ID использованного перехода |
| message      | string  | Сообщение о результате      |

## Возможные ошибки

### 400 Bad Request

```json
{
  "statusCode": 400,
  "message": "Переход в указанный статус недоступен",
  "error": "Bad Request"
}
```

### 404 Not Found

```json
{
  "statusCode": 404,
  "message": "Задача не найдена",
  "error": "Not Found"
}
```

## Доступные статусы

- **New** - Новая задача
- **backlog** - Бэклог
- **Questions** - Вопросы
- **In Progress** - В работе
- **Review** - На проверке
- **Done** - Завершено

## Примечания

- Система автоматически определяет доступные переходы для текущего статуса задачи
- Если прямой переход недоступен, возвращается ошибка 400
- Комментарий добавляется к истории переходов задачи
- Перемещение логируется в Jira со всеми деталями

## Теги Swagger

- **tasks** - Эндпойнты для работы с задачами
