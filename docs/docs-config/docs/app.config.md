# app.config.ts

## Описание
Этот файл отвечает за основную конфигурацию приложения.

## Действия
- Регистрирует базовые настройки приложения
- Настраивает порт сервера через переменную PORT
- Определяет окружение (development/production)
- Устанавливает секретный ключ для webhook безопасности
- Предоставляет типизированный интерфейс AppConfig

## Переменные окружения
- PORT: порт сервера (по умолчанию 3000)
- NODE_ENV: окружение приложения
- WEBHOOK_SECRET: секрет для webhook безопасности

## Результат
- Типизированная конфигурация приложения
- Доступ через ConfigService в сервисах
- Автоматическое преобразование типов
