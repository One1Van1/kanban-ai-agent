# claude.config.ts

## Описание
Этот файл отвечает за конфигурацию Claude AI API.

## Действия
- Регистрирует настройки для Claude 3.5 Sonnet
- Устанавливает API ключ OpenRouter
- Настраивает модель AI (по умолчанию claude-3-sonnet)
- Определяет максимальное количество токенов
- Настраивает температуру генерации (креативность)

## Переменные окружения
- CLAUDE_API_KEY: API ключ OpenRouter
- CLAUDE_MODEL: модель Claude для использования
- CLAUDE_MAX_TOKENS: максимум токенов (по умолчанию 1000)
- CLAUDE_TEMPERATURE: температура (по умолчанию 0.7)

## Результат
- Конфигурация для Claude Vision API
- Настройки качества анализа фотографий
- Параметры генерации ответов AI
