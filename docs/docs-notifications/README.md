# 📧 Notifications - Документация

Папка `notifications` отвечает за отправку уведомлений через различные каналы связи для Kanban AI Agent.

## 📁 Структура папки

- **send-email** - Отправка email уведомлений через SMTP
- **send-telegram** - Отправка сообщений через Telegram Bot API

## 🎯 Основная функция

Обеспечивает доставку уведомлений пользователям о изменениях в задачах и работе AI агента.
