# send-telegram

## Описание

Этот файл отвечает за отправку сообщений через Telegram Bot API.

## Действия

- Подключается к Telegram Bot API с токеном
- Отправляет сообщение указанному пользователю
- Поддерживает форматирование текста (HTML, Markdown)
- Поддерживает тихие уведомления
- Логирует успешную отправку сообщения
- Обрабатывает ошибки API

## API

`POST /notifications/telegram`

## Входные данные

- chatId: ID чата или username получателя
- text: текст сообщения
- parseMode: режим форматирования (HTML/Markdown, опционально)
- disableWebPagePreview: отключить превью ссылок (опционально)
- disableNotification: тихое уведомление (опционально)

## Результат

- success: статус успешности
- messageId: ID сообщения в Telegram
- chatId: ID чата получателя
- message: описание результата
