# send-email

## Описание

Этот файл отвечает за отправку email уведомлений через SMTP протокол.

## Действия

- Подключается к SMTP серверу с аутентификацией
- Отправляет email указанному получателю
- Поддерживает HTML и текстовое форматирование
- Поддерживает CC и BCC получателей
- Логирует успешную отправку email
- Обрабатывает ошибки SMTP

## API

`POST /notifications/email`

## Входные данные

- to: email получателя
- subject: тема письма
- text: текстовое содержимое
- html: HTML содержимое (опционально)
- cc: копии (опционально)
- bcc: скрытые копии (опционально)

## Результат

- success: статус успешности
- messageId: ID сообщения от почтовой службы
- message: описание результата
