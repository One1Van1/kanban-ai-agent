# 📋 Types - Документация

Папка `types` содержит TypeScript интерфейсы и типы для работы с Jira.

## 📁 Структура папки

- **jira-board.interface.ts** - Интерфейсы для работы с канбан досками
- **jira-task.interface.ts** - Интерфейсы для работы с задачами Jira
- **kanban-column.interface.ts** - Интерфейсы для колонок канбан доски

## 🎯 Основная функция

Обеспечивает строгую типизацию для:
- **Jira API** ответов и запросов
- **Канбан досок** и их конфигурации
- **Задач** и их полей
- **Колонок** и статусов

## 🏗️ Архитектура

Все типы используются в сервисах и контроллерах для обеспечения type safety и автодополнения в IDE.
