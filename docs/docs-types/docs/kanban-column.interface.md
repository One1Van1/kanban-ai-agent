# kanban-column.interface.ts

## Описание
Этот файл отвечает за типизацию колонок канбан доски и фильтрации задач.

## Основные интерфейсы
- **KanbanColumn** - структура колонки канбан (name, statuses, limits)
- **KanbanColumnFilter** - фильтры для поиска задач в колонке
- **TaskFilterOptions** - опции фильтрации задач (проект, исполнитель, приоритет)
- **KanbanTaskSummary** - краткая информация о задаче в колонке
- **ColumnTasksResponse** - ответ с задачами из колонки

## Фильтрация задач
- По **проекту** (projectKey)
- По **исполнителю** (assigneeId, assigneeDisplayName)
- По **приоритету** (priority)
- По **типу задачи** (issueType)
- По **меткам** (labels)
- С **пагинацией** (maxResults, startAt)

## Сортировка
- По **дате создания** (created)
- По **дате обновления** (updated)
- По **приоритету** (priority)
- По **сроку выполнения** (duedate)
- **Направление**: ASC/DESC

## Результат
- Удобная работа с канбан колонками
- Гибкая фильтрация и сортировка задач
- Оптимизация производительности через пагинацию
