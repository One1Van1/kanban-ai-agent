# AI Анализ фотографий 🤖

Подробное описание работы AI анализа стрижек с помощью Claude 3.5 Sonnet Vision API.

## 🎯 Как это работает

Система автоматически анализирует фотографии стрижек при переводе задачи в определённые статусы:

1. **Детекция события** - webhook от Jira при изменении статуса
2. **Поиск фотографий** - автоматический поиск изображений "до" и "после"
3. **AI анализ** - отправка фото в Claude 3.5 Sonnet
4. **Обработка результата** - парсинг ответа и извлечение данных
5. **Сохранение** - добавление комментария с результатами в задачу

## ⚡ Триггеры анализа

### Статусы запуска

Анализ автоматически запускается при переводе задачи в статусы:

- **Review** 🔍
- **Testing** 🧪
- **Done** ✅

### Условия запуска

1. Задача содержит ключевые слова стрижки
2. В задаче есть прикреплённые изображения
3. Найдены фото "до" и "после"
4. Анализ ещё не выполнялся

## 📸 Поиск фотографий

### Автоматическая детекция

Система ищет изображения по двум алгоритмам:

#### 1. По ключевым словам в названии

```
Ключевые слова "ДО":
- "до", "before", "start", "начал", "было"

Ключевые слова "ПОСЛЕ":
- "после", "after", "finish", "result", "готов", "сделал"
```

#### 2. По времени загрузки

Если ключевые слова не найдены:

- **Фото "ДО"** = самое раннее изображение
- **Фото "ПОСЛЕ"** = самое позднее изображение

### Поддерживаемые форматы

- JPG, JPEG
- PNG
- GIF
- BMP
- WEBP

### Ограничения

- Максимальный размер: **10MB**
- Минимальное разрешение: **100x100px**

## 🧠 AI Анализ Claude

### Модель

По умолчанию используется: **Claude 3.5 Sonnet**

- Высокое качество анализа изображений
- Понимание контекста стрижек
- Генерация детальных комментариев

### Промпт для анализа

Claude получает специальный промпт:

```
Проанализируй фотографии стрижки ДО и ПОСЛЕ.

Критерии оценки:
1. Качество выполнения стрижки (техника, ровность, стиль)
2. Соответствие желаемому результату
3. Общий внешний вид и аккуратность
4. Профессионализм выполнения

Дополнительно определи:
- Пол клиента (мужской/женский)
- Тип стрижки (например: каре, боб, андеркат, fade и т.д.)

Ответ в JSON формате:
{
  "score": число от 1 до 10,
  "analysis": "детальный анализ работы",
  "recommendations": "рекомендации по улучшению",
  "clientInfo": {
    "gender": "мужской/женский",
    "haircutStyle": "название стиля стрижки"
  }
}
```

### Результат анализа

Claude возвращает структурированный JSON с:

```json
{
  "score": 8,
  "analysis": "Качественная стрижка с ровными линиями...",
  "recommendations": "Рекомендуется больше внимания к...",
  "clientInfo": {
    "gender": "женский",
    "haircutStyle": "каре"
  }
}
```

## 📊 Оценка качества

### Шкала оценок (1-10)

- **1-3** 🔴 **Неудовлетворительно**
  - Грубые ошибки в технике
  - Неровные линии, плохое качество

- **4-5** 🟡 **Удовлетворительно**
  - Базовое выполнение задачи
  - Есть недочёты, но в целом приемлемо

- **6-7** 🟢 **Хорошо**
  - Качественная работа
  - Незначительные недочёты

- **8-9** 🔵 **Отлично**
  - Высокое качество исполнения
  - Профессиональный результат

- **10** 🟣 **Превосходно**
  - Идеальное выполнение
  - Выдающееся качество

## 🚨 Обработка ошибок

### Типичные ошибки

**1. Фотографии не найдены**

```
❌ **НЕТ РЕЗУЛЬТАТА ВЫПОЛНЕНИЯ РАБОТЫ**
📷 В задаче отсутствуют фотографии результата работы
```

**2. Claude API недоступен**

```
⚠️ **ОШИБКА АНАЛИЗА**
Временные проблемы с AI сервисом. Попробуйте позже.
```

**3. Неподдерживаемый формат**

```
❌ **НЕПОДДЕРЖИВАЕМЫЙ ФОРМАТ**
Загрузите изображения в формате JPG, PNG, GIF, BMP или WEBP
```

**4. Превышен размер файла**

```
❌ **ФАЙЛ СЛИШКОМ БОЛЬШОЙ**
Максимальный размер изображения: 10MB
```

### Повторные попытки

Система автоматически повторяет анализ при ошибках:

- **Сетевые ошибки**: 3 попытки с интервалом 5 сек
- **Ошибки API**: 2 попытки с интервалом 10 сек
- **Таймауты**: 1 повторная попытка

## 🎭 Примеры использования

### Сценарий 1: Автоматический анализ

1. Создать задачу "Сделай стрижку КАН-100"
2. Прикрепить фото "до_стрижки.jpg"
3. Выполнить стрижку
4. Прикрепить фото "после_стрижки.jpg"
5. Перевести задачу в статус "Review"
6. **Результат**: Автоматический анализ и оценка от Claude

```bash

  -H "Content-Type: application/json" \
  -d '{
    "taskKey": "KAN-100",
    "beforeImageUrl": "https://example.com/before.jpg",
    "afterImageUrl": "https://example.com/after.jpg"
  }'
```
