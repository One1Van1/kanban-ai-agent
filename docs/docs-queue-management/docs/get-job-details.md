# get-job-details

## Описание

Этот файл отвечает за получение детальной информации о конкретной задаче в очереди.

## Действия

- Поиск задачи по ID
- Получает текущий статус задачи
- Отображает прогресс выполнения
- Показывает логи ошибок
- Обрабатывает отсутствие задачи

## API

`GET /queue/jobs/:jobId`

## Входные данные

- jobId: уникальный идентификатор задачи (в URL)

## Результат

- jobId: идентификатор задачи
- status: текущий статус
- progress: процент выполнения
- data: данные задачи
- error: информация об ошибках (если есть)
