# get-queue-status

## Описание

Этот файл отвечает за получение статуса работы очередей.

## Действия

- Получает общую статистику очередей
- Подсчитывает количество задач по статусам
- Проверяет состояние обработчиков
- Отображает метрики производительности

## API

`GET /queue/status`

## Входные данные

Нет (параметры не требуются)

## Результат

- queues: список очередей со статистикой
- totalJobs: общее количество задач
- activeJobs: количество активных задач
- completedJobs: количество завершенных задач
