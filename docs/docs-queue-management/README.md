# ⚡ Queue Management - Документация

Папка `queue-management` отвечает за управление очередями задач и фоновую обработку.

## 📁 Структура папки

- **create-task-queue** - Добавление задач в очередь обработки
- **get-queue-status** - Получение статуса работы очередей
- **get-job-details** - Получение детальной информации о задаче в очереди
- **process-task-queue** - Процессор для обработки задач из очереди

## 🎯 Основная функция

Обеспечивает масштабируемую фоновую обработку задач через Bull Queue с использованием Redis.
