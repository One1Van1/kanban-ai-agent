# ai-reporting.module.ts

## Описание
Этот файл отвечает за модуль AI отчетов и аналитики.

## Действия
- Автоматически загружает все контроллеры из папки ai-reporting
- Автоматически загружает все сервисы из папки ai-reporting
- Подключает зависимости из jira-integration (SearchTasks, AddComment, MoveTask)
- Импортирует ConfigModule для доступа к конфигурации
- Организует все компоненты AI отчетности в единый модуль

## Зависимости
- SearchTasksService - для поиска задач в Jira
- AddTaskCommentService - для добавления комментариев с отчетами
- MoveTaskService - для автоматического движения задач
- ConfigModule - для доступа к настройкам

## Результат
- Полностью настроенный модуль AI отчетов
- Авто-загрузка всех компонентов
- Готовность к обработке запросов на генерацию отчетов
