# photo-analysis.module.ts

## Описание
Этот файл отвечает за модуль анализа фотографий через Claude AI.

## Действия
- Автоматически загружает все контроллеры из папки photo-analysis
- Автоматически загружает все сервисы из папки photo-analysis
- Импортирует ConfigModule для доступа к Claude конфигурации
- Организует компоненты анализа фотографий в единый модуль
- Обеспечивает интеграцию с Claude 3.5 Sonnet Vision API

## Зависимости
- ConfigModule - для доступа к настройкам Claude API
- Axios - для HTTP запросов к OpenRouter
- Claude Vision API - для анализа изображений

## Результат
- Полностью настроенный модуль анализа фотографий
- Авто-загрузка всех компонентов
- Готовность к обработке запросов на анализ стрижек
