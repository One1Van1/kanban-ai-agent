# Пользовательские сценарии 👥

Практические примеры использования Kanban AI Agent в реальных условиях.

## 🎯 Основные роли пользователей

### 👨‍💼 Мастер (исполнитель стрижек)

- Создаёт задачи на стрижки
- Прикрепляет фотографии результата
- Получает автоматическую оценку работы

### 👩‍💼 Администратор салона

- Запрашивает отчёты по работе
- Анализирует качество услуг
- Планирует загрузку по дням

### 🤖 AI Агенты

- **Claude Agent** - анализирует качество стрижек
- **Report Agent** - генерирует аналитические отчёты

## 📋 Сценарий 1: Выполнение стрижки

### 🎬 Описание

Мастер выполняет стрижку клиента и получает автоматическую оценку качества работы.

### 👤 Участники

- **Мастер Анна** (исполнитель)
- **Claude Agent** (AI анализатор)

### 📝 Пошаговый процесс

#### Шаг 1: Создание задачи

**Мастер Анна:**

1. Открывает Jira
2. Создаёт новую задачу:
   - Тип: Task
   - Название: "Сделай стрижку женское каре"
   - Описание: "Клиентка просит классическое каре до плеч"
   - Назначает на себя

#### Шаг 2: Начало работы

**Мастер Анна:**

1. Делает фото клиента "до" стрижки
2. Прикрепляет фото к задаче (название: "до_стрижки.jpg")
3. Переводит задачу в статус "In Progress"
4. Выполняет стрижку

#### Шаг 3: Завершение работы

**Мастер Анна:**

1. Делает фото результата "после" стрижки
2. Прикрепляет фото к задаче (название: "после_стрижки.jpg")
3. Переводит задачу в статус "Review"

#### Шаг 4: Автоматический анализ

**Claude Agent:**

1. Получает webhook о смене статуса на "Review"
2. Находит задачу со словом "стрижк"
3. Обнаруживает фотографии "до" и "после"
4. Отправляет изображения в Claude 3.5 Sonnet
5. Анализирует качество стрижки
6. Добавляет комментарий с результатом:

```
🤖 *АНАЛИЗ CLAUDE 3.5 SONNET* 🤖

📊 *РЕЗУЛЬТАТ АНАЛИЗА СТРИЖКИ*
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⭐ **ОЦЕНКА: 8/10**

👤 **ИНФОРМАЦИЯ О КЛИЕНТЕ**
• Пол: Женский
• Стиль стрижки: Каре

🔍 **ДЕТАЛЬНЫЙ АНАЛИЗ**
Качественно выполненное каре с ровными линиями
и хорошей геометрией. Длина соответствует пожеланиям
клиента. Переходы плавные, общий вид аккуратный.

💡 **РЕКОМЕНДАЦИИ**
Отличная работа! Небольшая корректировка в области
висков сделает результат ещё более совершенным.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🕒 *Анализ выполнен: 04.10.2025, 16:30*
```

7. Автоматически переводит задачу в "Done"

#### Результат

✅ Мастер получает объективную оценку работы  
✅ Клиент видит профессиональный подход  
✅ Данные сохраняются для отчётности

## 📊 Сценарий 2: Еженедельный отчёт

### 🎬 Описание

Администратор салона запрашивает аналитический отчёт по работе за неделю.

### 👤 Участники

- **Администратор Мария** (руководитель)
- **Report Agent** (AI аналитик)

### 📝 Пошаговый процесс

#### Шаг 1: Запрос отчёта

**Администратор Мария:**

1. Открывает Jira
2. Создаёт новую задачу:
   - Тип: Task
   - Название: "Еженедельная аналитика"
   - Описание: "сделай отчёт за прошлую неделю"
   - Назначает на: "AI-Report-maker"

#### Шаг 2: Автоматическая генерация

**Report Agent:**

1. Получает webhook о назначении на AI-Report-maker
2. Парсит период "прошлая неделя" (22.09-28.09.2025)
3. Ищет все завершённые анализы стрижек за период
4. Находит 15 выполненных работ
5. Анализирует данные по категориям:
   - Общая статистика
   - Разбивка по полу клиентов
   - Популярные стили стрижек
   - Нагрузка по дням недели
   - Качество работы

#### Шаг 3: Результат отчёта

**Report Agent добавляет комментарий:**

```
📊 **ОТЧЁТ О СТРИЖКАХ**
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📈 **ОБЩАЯ СТАТИСТИКА**
• Всего стрижек: 15
• Период: 22.09.2025 - 28.09.2025
• Средняя оценка: 7.4/10
• Лучшая оценка: 9/10 (Анна)
• Худшая оценка: 6/10

👥 **АНАЛИЗ ПО ПОЛУ**
• 👨 Мужчины: 9 стрижек (60%)
  └── Средняя оценка: 7.8/10
• 👩 Женщины: 6 стрижек (40%)
  └── Средняя оценка: 6.8/10

✂️ **ПОПУЛЯРНЫЕ СТИЛИ СТРИЖЕК**
• Fade: 4 стрижки (26.7%)
• Каре: 3 стрижки (20.0%)
• Боб: 2 стрижки (13.3%)
• Андеркат: 2 стрижки (13.3%)

📅 **НАГРУЗКА ПО ДНЯМ НЕДЕЛИ**
• Понедельник: 1 стрижка
• Вторник: 2 стрижки
• Среда: 3 стрижки
• Четверг: 4 стрижки ⭐ (пик)
• Пятница: 3 стрижки
• Суббота: 2 стрижки
• Воскресенье: 0 стрижек

⭐ **КАЧЕСТВО РАБОТЫ**
• Отличные (8-10): 6 работ (40%)
• Хорошие (6-7): 9 работ (60%)
• Удовлетворительные (4-5): 0 работ
• Неудовлетворительные (1-3): 0 работ

🎯 **ВЫВОДЫ И РЕКОМЕНДАЦИИ**
• Стабильно высокое качество работы
• Пик загрузки в четверг - планировать больше мастеров
• Мужские стрижки показывают лучшие результаты
• Популярность современных стилей (Fade, Андеркат)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📅 Отчёт сгенерирован: 29.09.2025, 18:00
🤖 AI Reporting Agent v1.0
```

#### Результат

✅ Администратор получает детальную аналитику  
✅ Выявлены пики загрузки для планирования  
✅ Определены сильные стороны команды

## 🚨 Сценарий 3: Исправление ошибок

### 🎬 Описание

В задаче отсутствуют фотографии результата, система сообщает об ошибке.

### 👤 Участники

- **Мастер Виктор** (новичок)
- **Claude Agent** (AI анализатор)

### 📝 Пошаговый процесс

#### Шаг 1: Неправильное выполнение

**Мастер Виктор:**

1. Создаёт задачу "Сделай стрижку мужская"
2. Переводит в "In Progress"
3. Выполняет стрижку
4. **Забывает прикрепить фотографии**
5. Переводит задачу в "Review"

#### Шаг 2: Обнаружение ошибки

**Claude Agent:**

1. Получает webhook о смене статуса
2. Анализирует задачу
3. Не находит прикреплённых изображений
4. Добавляет комментарий об ошибке:

```
❌ **НЕТ РЕЗУЛЬТАТА ВЫПОЛНЕНИЯ РАБОТЫ**

📷 В задаче отсутствуют фотографии результата работы (до/после).

🔧 **ЧТО НУЖНО СДЕЛАТЬ:**
1. Прикрепите фото "ДО" стрижки
2. Прикрепите фото "ПОСЛЕ" стрижки
3. Переведите задачу обратно в "Review"

📝 **ТРЕБОВАНИЯ К ФОТО:**
• Форматы: JPG, PNG, GIF, BMP, WEBP
• Максимальный размер: 10MB
• Рекомендуемые названия: "до.jpg", "после.jpg"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🕒 *Проверка выполнена: 04.10.2025, 17:15*
```

5. Переводит задачу обратно в "In Progress"

#### Шаг 3: Исправление

**Мастер Виктор:**

1. Читает комментарий с инструкциями
2. Прикрепляет фотографии "до" и "после"
3. Снова переводит в "Review"
4. Получает корректный анализ от Claude

#### Результат

✅ Обучение мастера правильному процессу  
✅ Контроль качества выполнения задач  
✅ Автоматическая валидация процесса

## 🔧 Сценарий 5: Настройка и тестирование

### 🎬 Описание

IT-администратор настраивает систему и проверяет её работу.

### 👤 Участники

- **IT-администратор Алексей**

### 📝 Пошаговый процесс

#### Шаг 1: Проверка подключений

```bash
# Проверка основного приложения
curl http://localhost:3000
# Ответ: {"message": "Kanban AI Agent is running!"}

# Проверка Jira подключения
curl http://localhost:3000/jira/health
# Ответ: {"status": "healthy", "jiraConnected": true}

# Проверка Claude webhook
curl http://localhost:3000/jira/process-webhook-before-after/health
# Ответ: {"status": "healthy", "claudeEndpoint": "..."}
```

#### Шаг 2: Тестирование webhook

```bash
# Получение текущего ngrok URL
curl -s http://localhost:4040/api/tunnels | jq -r '.tunnels[0].public_url'

# Обновление webhook в Jira
# https://abc123.ngrok-free.app/jira/process-webhook-before-after
```

#### Шаг 3: Тестовая задача

1. Создать задачу "Тест Claude анализ"
2. Прикрепить тестовые фотографии
3. Перевести в "Review"
4. Проверить автоматический анализ

#### Результат

✅ Система настроена корректно

## 💡 Полезные советы

### Для мастеров

- **Качественные фото:** Снимайте при хорошем освещении
- **Чёткие названия:** "до.jpg", "после.jpg" для автоопределения
- **Статусы:** Переводите в Review только с готовыми фото

### Для администраторов

- **Регулярные отчёты:** Создавайте еженедельные задачи на отчёты
- **Анализ трендов:** Сравнивайте отчёты разных периодов
- **Планирование:** Используйте данные о пиках загрузки

### Для IT

- **Мониторинг:** Регулярно проверяйте health endpoints
- **Логи:** Следите за ошибками в логах приложения
- **Backup:** Сохраняйте конфигурацию webhook в Jira
