# Прогресс по интеграциям

## AI Провайдеры

### Варианты

- **OpenAI GPT-4/3.5** - хорошая документация, много примеров
- **Anthropic Claude** - хорошие возможности анализа
- **Google Gemini** - новый, интересные возможности
- **Локальные модели** - больше контроля, но сложнее настройка

### Выбор: ✅ **Anthropic Claude**

**Обоснование выбора:**

- Отличные возможности анализа и рассуждений
- Хорошо понимает контекст задач
- Качественные решения для классификации
- Стабильное API

**Пакет:** `@anthropic-ai/sdk`

## Kanban Системы

### Варианты

- **Trello** - простое API, webhook'и
- **GitHub Projects** - интеграция с GitHub, REST API
- **Jira** - мощный функционал, сложное API
- **Notion** - гибкость, API развивается
- **Linear** - современное API

### Выбор: ✅ **Jira**

**Обоснование выбора:**

- Мощный функционал для управления задачами
- Развитая система webhook'ов
- Гибкая настройка workflow'ов
- Широкое использование в enterprise

**Пакет:** `atlassian-js-api` или нативный HTTP клиент

**Использование:**

- **Тестирование:** Создадим тестовый проект в Jira
- **Продакшен:** Тот же код, другие credentials и проекты

## Планы интеграции

- ✅ **AI провайдер:** Anthropic Claude
- ✅ **Kanban система:** Jira
