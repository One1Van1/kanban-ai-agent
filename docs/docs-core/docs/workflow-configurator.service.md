# workflow-configurator.service.ts

## Описание
Этот файл отвечает за автоматическую настройку Jira workflow для логирования времени.

## Действия
- Создает экраны (Screens) для логирования времени работы
- Настраивает схемы экранов (Screen Schemes) для разных переходов
- Конфигурирует Workflow с автоматическим логированием времени
- Связывает экраны с переходами между статусами
- Устанавливает поля для ввода времени работы над стрижками

## API методы
- createTimeLoggingScreen() - создание экрана логирования времени
- createScreenScheme() - создание схемы экранов
- configureWorkflow() - настройка workflow процесса
- associateScreenWithTransition() - связывание экрана с переходом

## Настройки workflow
- Автоматическое логирование времени при переходах
- Обязательные поля для ввода времени
- Связь с типами задач (Story, Task, Bug)

## Результат
- Полностью настроенный workflow для учета времени
- Автоматическое отслеживание работы над стрижками
- Интеграция с системой аналитики времени
