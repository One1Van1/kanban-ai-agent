# app.service.ts

## Описание
Этот файл отвечает за главный сервис приложения.

## Действия
- Предоставляет базовый метод getHello()
- Возвращает приветственное сообщение "Hello World!"
- Служит примером простого сервиса в NestJS

## Методы
- **getHello()** - возвращает строку приветствия

## Входные данные
Нет входных параметров

## Результат
- Строка "Hello World!"
- Подтверждение работы основного сервиса
