# process-report-task

## Описание

Этот файл отвечает за автоматическую обработку задач с запросами отчетов.

## Действия

- Получает детали задачи из Jira
- Проверяет, назначена ли задача на AI-Report-maker
- Извлекает период дат из описания задачи
- Генерирует отчет через generate-report сервис
- Добавляет результат отчета в комментарий к задаче
- Перемещает задачу в статус Done
- Обрабатывает ошибки и логирует процесс

## API

`POST /ai-reporting/process-report-task`

## Входные данные

- taskKey: ключ задачи с запросом отчета

## Результат

- Успешность обработки
- Сообщение о результате
- Автоматическое обновление задачи в Jira
