# 🌐 Альтернативы для webhook'ов

## 🎯 Проблема

Jira в интернете не может отправлять webhook'и на localhost:3000

## 🛠 Решения (от простого к сложному)

### 1. 🔥 LocalTunnel (САМЫЙ ПРОСТОЙ!)

```bash
# Установка и запуск одной командой
npx localtunnel --port 3000

# Получите URL вроде: https://silly-dog-12.loca.lt
```

**Плюсы**: Не требует регистрации, мгновенный старт
**Минусы**: Менее стабильный чем ngrok

### 2. 🌩 Cloudflare Tunnel (НАДЕЖНЫЙ!)

```bash
# Установка (Mac)
brew install cloudflare/cloudflare/cloudflared

# Запуск
cloudflared tunnel --url http://localhost:3000
```

**Плюсы**: Быстрый, стабильный, от Cloudflare
**Минусы**: Требует установки дополнительного ПО

### 3. 🔗 Serveo (ЧЕРЕЗ SSH!)

```bash
# Просто одна команда
ssh -R 80:localhost:3000 serveo.net
```

**Плюсы**: Использует SSH, не требует установки
**Минусы**: Может блокироваться файрволлами

### 4. 🚀 ngrok (ПОПУЛЯРНЫЙ!)

```bash
# После регистрации
ngrok http 3000
```

**Плюсы**: Очень популярный, много функций
**Минусы**: Требует регистрацию для постоянного использования

## 🎪 Демо-режим без webhook'ов

Можете продолжать тестировать через curl:

```bash
curl -X POST http://localhost:3000/webhook/jira -H "Content-Type: application/json" -d '{"webhookEvent": "jira:issue_created", "issue": {...}}'
```

## 🏆 Рекомендация

**Для быстрого тестирования**: LocalTunnel
**Для серьезного использования**: Cloudflare Tunnel или ngrok

## ❓ Какой выберете?

1. **LocalTunnel** - просто запустить сейчас
2. **Настроить ngrok** - если хотите "как положено"
3. **Cloudflare** - если нужна максимальная надежность
4. **Остаться с curl** - для ручного тестирования
