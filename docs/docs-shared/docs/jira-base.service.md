# jira-base.service.ts

## Описание
Этот файл отвечает за базовые операции с Jira REST API.

## Действия
- Создает HTTP клиент с аутентификацией для Jira
- Предоставляет методы для работы с задачами (получение, создание, обновление)
- Управляет комментариями и прикрепленными файлами
- Обрабатывает переходы между статусами задач
- Работает с канбан досками и колонками
- Логирует все операции и обрабатывает ошибки

## API методы
- getTask() - получение задачи по ключу
- searchTasks() - поиск задач по JQL
- createTask() - создание новой задачи
- updateTask() - обновление задачи
- addComment() - добавление комментария
- getTransitions() - получение переходов
- transitionTask() - выполнение перехода

## Результат
- Полная интеграция с Jira REST API
- Типизированные интерфейсы для всех операций
- Централизованная обработка ошибок
