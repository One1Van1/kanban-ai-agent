# 🔧 Shared - Документация

Папка `shared` содержит общие сервисы и утилиты для работы с Jira.

## 📁 Структура папки

### jira/
- **jira-base.service.ts** - Базовый сервис для работы с Jira API
- **jira-time-logger.service.ts** - Логирование времени выполнения задач
- **workflow-configurator.service.ts** - Конфигурация workflow процессов

## 🎯 Основная функция

Предоставляет общую функциональность для всех модулей:
- **Базовые операции** с Jira API
- **Аутентификация** и HTTP клиент
- **Автоматическое логирование** времени работы AI
- **Конфигурация workflow** для разных типов задач

## 🏗️ Архитектура

Shared сервисы используются как зависимости в feature модулях, обеспечивая переиспользование кода.
