# AI Отчёты и аналитика 📊

Автоматическая генерация детальных отчётов по анализам стрижек с аналитикой и статистикой.

## 🎯 Что такое AI отчёты

AI Reporting Agent анализирует все выполненные анализы стрижек и генерирует комплексные отчёты с:

- 📈 **Общей статистикой** (количество, качество, периоды)
- 👥 **Анализом по полу** клиентов (мужчины/женщины)
- ✂️ **Популярными стилями** стрижек
- 📅 **Нагрузкой по дням недели** (понедельник-воскресенье)
- ⭐ **Качеством работы** (средние оценки)
- 📊 **Трендами и сравнениями** по периодам

## ⚡ Как запустить отчёт

### Автоматический запуск через Jira

1. **Создать задачу** любого типа в Jira
2. **Указать описание** с периодом отчёта:
   - "сделай отчёт за сегодня"
   - "отчёт за прошлую неделю"
   - "статистика за последние 30 дней"
3. **Назначить на AI-Report-maker**
4. **Перевести в статус "In Progress"**
5. **Получить готовый отчёт** в комментариях задачи

### Ручной запуск через API

```bash
curl -X POST http://localhost:3000/ai-reporting-agent/generate-report \
  -H "Content-Type: application/json" \
  -d '{
    "dateRange": "прошлая неделя",
    "includeDetails": true
  }'
```

## 📅 Поддерживаемые периоды

### Естественный язык

Система понимает русские фразы:

- **"сегодня"** / **"за сегодня"**
- **"вчера"** / **"за вчера"**
- **"завтра"** (для планирования)
- **"прошлую неделю"** / **"за прошлую неделю"**
- **"этот месяц"** / **"за этот месяц"**
- **"последние 7 дней"** / **"за последние 7 дней"**
- **"последние 30 дней"**

### Точные даты

Можно указать конкретный период:

- **"с 01.10.2025 по 07.10.2025"**
- **"2025-10-01 to 2025-10-07"**

## 🔍 Источники данных

### Откуда берутся данные

1. **Поиск задач**: Все завершённые задачи с ключевыми словами стрижки
2. **Фильтрация**: По дате AI анализа (не дате завершения задачи)
3. **Парсинг комментариев**: Извлечение данных из комментариев Claude
4. **Агрегация**: Подсчёт статистики и генерация выводов

### JQL запрос

```sql
project = KAN AND summary ~ "стрижк*" AND status = Done
```

## 🤖 Извлечение данных AI

### Парсинг комментариев Claude

Система анализирует комментарии и извлекает:

#### Оценка качества

```javascript
// Поиск паттернов: "7/10", "Оценка: 8", "Score: 9"
const scorePatterns = [/(\d+)\/10/g, /оценка:\s*(\d+)/gi, /score:\s*(\d+)/gi];
```

#### Пол клиента

```javascript
// Извлечение из JSON или текста
const genderPatterns = [
  /"gender":\s*"(мужской|женский)"/gi,
  /пол:\s*(мужской|женский)/gi,
  /(мужчина|женщина|мужской|женский)/gi,
];
```

#### Стиль стрижки

```javascript
// Извлечение стиля из комментариев
const stylePatterns = [
  /"haircutStyle":\s*"([^"]+)"/gi,
  /стиль:\s*([^\n,\.]+)/gi,
  /(каре|боб|fade|андеркат|pixie|лоб)/gi,
];
```

## 🚨 Обработка ошибок

### Типичные проблемы

**1. Нет данных за период**

```
📊 **ОТЧЁТ О СТРИЖКАХ**
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ **НЕТ ДАННЫХ**
За указанный период не найдено завершённых
анализов стрижек.

Период: 04.10.2025 - 04.10.2025
```

**2. Ошибка парсинга дат**

```
❌ **ОШИБКА ПАРСИНГА ДАТЫ**
Не удалось распознать период: "неизвестная фраза"

Поддерживаемые форматы:
• "сегодня", "вчера", "прошлая неделя"
• "последние 7 дней"
• "с 01.10.2025 по 07.10.2025"
```

**3. Проблемы с Jira API**

```
⚠️ **ОШИБКА ПОЛУЧЕНИЯ ДАННЫХ**
Временные проблемы с подключением к Jira.
Попробуйте создать отчёт позже.
```
