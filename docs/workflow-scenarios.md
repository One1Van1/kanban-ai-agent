# Kanban AI Agent - Сценарии работы

## 📋 Workflow колонок

### Колонки Kanban доски:

- **Backlog** - черновики задач
- **New** - готовые к выполнению задачи
- **In Progress** - задачи в работе у AI агента
- **Questions** - задачи, требующие уточнений
- **Review** - выполненные задачи на проверке
- **Done** - завершенные задачи

## 🔄 Сценарии перемещения задач

### 1. Создание задачи (Человек)

- **Кто**: Человек
- **Действие**: Создает черновик задачи в колонке **Backlog**
- **Статус**: Задача создана, но не готова к выполнению

### 2. Подготовка к выполнению (Человек)

- **Кто**: Человек
- **Действие**: Перетаскивает задачу из **Backlog** в **New**
- **Условие**: Только человек может это делать
- **Статус**: Задача готова для анализа AI агентом

### 3. Анализ и принятие решения (AI Agent)

- **Кто**: AI Agent
- **Источник**: Колонка **New**
- **Действие**: Анализирует задачу и принимает решение:

#### 3.1 Задача понятна → **In Progress**

- AI агент понимает требования
- Автоматически перемещает в **In Progress**
- Начинает выполнение задачи

#### 3.2 Задача не понятна → **Questions**

- AI агент не может понять требования
- Перемещает в **Questions**
- Добавляет комментарий с вопросами
- Ждет уточнений от человека

### 4. Выполнение задачи (AI Agent)

- **Кто**: AI Agent
- **Источник**: Колонка **In Progress**
- **Действие**: Выполняет задачу (создает код, файлы, etc.)
- **Результат**: После выполнения перемещает в **Review**

### 5. Проверка результата (Человек)

- **Кто**: Человек
- **Источник**: Колонка **Review**
- **Действие**: Проверяет результат работы AI агента
- **Результат**: Перемещает в **Done** или возвращает в **New** для доработки

## 🎯 Ключевые принципы

1. **Только человек** может перемещать задачи из **Backlog**
2. **AI Agent** автоматически работает только с колонкой **New**
3. **AI Agent** самостоятельно принимает решение: **In Progress** или **Questions**
4. **Все выполненные задачи** попадают в **Review** для человеческой проверки
5. **Прозрачность процесса** - каждое действие AI агента логируется и комментируется

## 🔧 Настройки AI Agent

- **Мониторинг**: Только колонка **New**
- **Автоматическое выполнение**: Задачи типа `code` с низкой/средней сложностью
- **Требуют одобрения**: Задачи типа `testing`, высокой сложности
- **Таймаут выполнения**: Настраиваемый лимит времени на задачу
