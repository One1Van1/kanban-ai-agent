# create-agent

## Описание

Этот файл отвечает за создание новых AI агентов в системе.

## Действия

- Проверяет валидность данных агента
- Генерирует уникальный ID агента
- Сохраняет конфигурацию агента
- Логирует создание агента
- Обрабатывает ошибки валидации

## API

`POST /ai-agent`

## Входные данные

- name: имя агента
- description: описание агента
- instructions: базовые инструкции
- enabled: статус активности

## Результат

- agentId: уникальный идентификатор
- success: статус создания
- message: описание результата
