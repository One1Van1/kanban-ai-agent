# 🔄 Правила переноса задач по колонкам

## Схема workflow

```
[Backlog] → [New] → [Questions/Review] → [Done/In Progress]
    ↑         ↑            ↑                    ↑
  Только    Агент      Агент/Человек       Человек
  человек   читает    создает/читает      управляет
```

## Описание колонок и правил

### 📋 **Backlog**

- **Назначение**: Хранение будущих задач
- **Доступ агента**: ❌ **ЗАПРЕЩЕН** - агент вообще не лезет в эту колонку
- **Управление**: Только человек может перемещать задачи отсюда

### 🆕 **New**

- **Назначение**: Задачи готовые к выполнению агентом
- **Доступ агента**: ✅ **ЧТЕНИЕ** - агент мониторит эту колонку
- **Логика агента**:
  - Читает и анализирует задачи
  - Если понимает → выполняет → переносит в **Review**
  - Если НЕ понимает → переносит в **Questions** с объяснением

### ❓ **Questions**

- **Назначение**: Задачи, которые агент не понял
- **Доступ агента**: ✅ **ЗАПИСЬ** - агент может помещать сюда задачи
- **Логика**:
  - Агент перемещает непонятные задачи из **New**
  - Добавляет комментарий с объяснением проблемы
  - Человек должен уточнить задачу и вернуть в **New**

### 👀 **Review**

- **Назначение**: Задачи выполненные агентом, ожидающие проверки
- **Доступ агента**: ✅ **ЗАПИСЬ** - агент помещает сюда выполненные задачи
- **Управление**: Только человек решает дальнейшую судьбу:
  - ✅ Одобрил → **Done**
  - ❌ Не одобрил → **In Progress** (с комментарием что переделать)

### 🔄 **In Progress**

- **Назначение**: Задачи требующие доработки после review
- **Доступ агента**: ✅ **ЧТЕНИЕ И ЗАПИСЬ** - агент мониторит и работает с этими задачами
- **Логика**:
  - Человек помещает сюда задачи из **Review** с комментариями
  - Агент читает комментарии и дорабатывает задачу
  - После доработки агент снова перемещает в **Review**

### ✅ **Done**

- **Назначение**: Полностью завершенные задачи
- **Доступ агента**: ❌ **ЗАПРЕЩЕН**
- **Управление**: Только человек перемещает сюда из **Review**

## Матрица доступов

| Колонка     | Агент читает | Агент пишет | Человек | Примечание           |
| ----------- | ------------ | ----------- | ------- | -------------------- |
| Backlog     | ❌           | ❌          | ✅      | Только планирование  |
| New         | ✅           | ❌          | ✅      | Входящие задачи      |
| Questions   | ❌           | ✅          | ✅      | Непонятные задачи    |
| Review      | ❌           | ✅          | ✅      | Проверка результатов |
| In Progress | ✅           | ✅          | ✅      | Активная доработка   |
| Done        | ❌           | ❌          | ✅      | Финальное состояние  |

## Алгоритм работы агента

```
1. Мониторинг [New] и [In Progress]
2. Для каждой задачи:
   └─ Анализ AI
      ├─ Понятна? ❌ → [Questions] + комментарий
      └─ Понятна? ✅ → Выполнение
                      ├─ Успех? ✅ → [Review]
                      └─ Ошибка? ❌ → [Questions] + описание ошибки
```

## Комментарии агента

- **В Questions**: "🤖 Не могу понять задачу. Проблема: [описание]"
- **В Review**: "🤖 Задача выполнена. Результат: [описание]"
- **После доработки**: "🤖 Задача доработана согласно комментариям"
