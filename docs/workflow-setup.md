# 🔄 Настройка Workflow в Jira

## 🎯 Цель

Настроить переходы между статусами, чтобы AI мог автоматически перемещать задачи:

- **New** → **Questions** (для неполных задач)
- **New** → **In Progress** (для готовых к работе задач)

## 📋 Пошаговая инструкция

### Способ 1: Через настройки доски (ПРОСТОЙ)

1. **Откройте конфигурацию доски:**

   ```
   https://sa4kov2004.atlassian.net/jira/software/projects/KAN/boards/1/config
   ```

2. **Перейдите в раздел "Columns" (Колонки)**

3. **Настройте статусы для каждой колонки:**
   - **New**: `To Do`, `New`
   - **Questions**: `Questions`
   - **In Progress**: `In Progress`
   - **Review**: `Review`, `In Review`
   - **Done**: `Done`, `Closed`

4. **Создайте недостающие статусы:**
   - Если статуса "Questions" нет, создайте его
   - Убедитесь что есть "In Progress"

### Способ 2: Через Workflow (ПРОДВИНУТЫЙ)

1. **Перейдите в Project Settings:**

   ```
   https://sa4kov2004.atlassian.net/jira/software/projects/KAN/settings/workflows
   ```

2. **Найдите активный workflow и нажмите "Edit"**

3. **Добавьте переходы (Transitions):**

   **Из статуса "New":**
   - ✅ **To Questions** → статус "Questions"
   - ✅ **To In Progress** → статус "In Progress"

   **Из статуса "Questions":**
   - ✅ **To In Progress** → статус "In Progress"
   - ✅ **Back to New** → статус "New"

4. **Сохраните и опубликуйте workflow**

## 🔧 Быстрое решение: Проверить текущие статусы

Проверим, какие статусы есть в проекте:

```bash
# Через REST API
curl -u "your-email@gmail.com:YOUR_JIRA_API_TOKEN" \
  "https://your-instance.atlassian.net/rest/api/3/project/YOUR_PROJECT_KEY/statuses"
```

## 🎯 Результат

После настройки AI сможет:

- ✅ Автоматически анализировать новые задачи
- ✅ Перемещать их в правильные колонки
- ✅ Обновлять статусы через Jira API

## 🚨 Если ничего не помогает

Можно настроить наш код для работы с существующими статусами:

- Использовать только переходы, которые доступны
- Добавить логику определения доступных переходов
- Создать mapping между AI решениями и реальными статусами
