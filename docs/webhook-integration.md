# 🎣 Webhook Integration для Jira

## Обзор

Система вебхуков позволяет автоматически реагировать на события в Jira без необходимости постоянного опроса API. Это кардинально улучшает производительность и отзывчивость вашего AI агента.

## 🚀 Преимущества вебхуков

### ✅ Мгновенная реакция

- События обрабатываются в реальном времени
- Нулевая задержка между событием в Jira и запуском AI анализа
- Автоматическая синхронизация состояния

### ⚡ Производительность

- Нет необходимости в постоянном опросе API
- Снижение нагрузки на сервер
- Экономия ресурсов и API лимитов

### 🎯 Точность

- Обработка только релевантных событий
- Полная информация о произошедших изменениях
- Контекст изменений через changelog

## 📡 Поддерживаемые события

### Основные события задач

- **`jira:issue_created`** - Создана новая задача
- **`jira:issue_updated`** - Задача обновлена
- **`jira:issue_deleted`** - Задача удалена

### События комментариев

- **`comment_created`** - Добавлен комментарий
- **`comment_updated`** - Комментарий обновлен
- **`comment_deleted`** - Комментарий удален

### События логов работы

- **`worklog_updated`** - Обновлен лог работы

## 🔗 Эндпойнты

### Основной обработчик вебхуков

```
POST /jira/webhook
```

Централизованный обработчик для всех типов событий Jira.

**Пример использования:**

```bash
curl -X POST http://localhost:3000/jira/webhook \
  -H "Content-Type: application/json" \
  -H "X-Jira-Signature: sha256=..." \
  -d '{
    "webhookEvent": "jira:issue_created",
    "issue": {
      "key": "PROJ-123",
      "fields": {
        "summary": "Сделать стрижку клиенту",
        "status": {
          "name": "To Do"
        }
      }
    }
  }'
```

### Специализированный обработчик для стрижек

```
POST /jira/webhook/haircut-tasks
```

Обработчик, настроенный специально для задач, связанных со стрижками и косметологией.

## ⚙️ Настройка в Jira

### 1. Создание вебхука в Jira

1. Зайдите в **Jira Administration** → **System** → **Webhooks**
2. Нажмите **Create a Webhook**
3. Заполните поля:

```
Name: AI Agent Webhook
Status: Enabled
URL: http://your-server.com:3000/jira/webhook
```

### 2. Выбор событий

Отметьте следующие события:

- ✅ Issue → Created
- ✅ Issue → Updated
- ✅ Issue → Deleted
- ✅ Comment → Created
- ✅ Worklog → Updated

### 3. JQL фильтр (опционально)

Для фильтрации только нужных задач:

```sql
project = YOUR_PROJECT_KEY
```

### 4. Настройка безопасности

В поле **Secret** укажите значение из `WEBHOOK_SECRET`.

## 🔧 Конфигурация

### Переменные окружения

```env
# Безопасность вебхуков
WEBHOOK_SECRET=your-webhook-secret-here

# URL для внутренних вызовов AI агента
APP_BASE_URL=http://localhost:3000

# Настройки обработки
WEBHOOK_DELAY_MS=2000
WEBHOOK_ENABLE_AI_ANALYSIS=true
WEBHOOK_ENABLE_NOTIFICATIONS=true
```

### Настройки в коде

```typescript
const config: WebhookProcessingConfig = {
  enableAiAnalysis: true,
  enableNotifications: true,
  enableAutoAssignment: false,
  haircutKeywords: [
    'стрижка',
    'haircut',
    'окрашивание',
    'укладка',
    'маникюр',
    'педикюр',
  ],
  delayMs: 2000,
};
```

## 🎯 Автоматические действия

### При создании новой задачи

1. **Анализ содержимого** - AI определяет тип задачи
2. **Классификация** - Автоматическая категоризация (стрижка/обычная задача)
3. **Уведомления** - Отправка уведомлений ответственным
4. **Метаданные** - Автоматическое добавление тегов и меток

### При изменении статуса

- **To Do → In Progress**: Запуск мониторинга прогресса
- **In Progress → Review**: Подготовка к проверке качества
- **Review → Done**: Анализ выполненной работы

### При добавлении комментария

- **Анализ содержимого** на предмет важных изменений
- **Извлечение ключевой информации**
- **Обновление приоритета** при обнаружении критических слов

## 🔄 Интеграция с AI агентом

### Автоматический запуск анализа

```typescript
// При создании задачи о стрижке
await this.triggerAiAction(AIAgentAction.ANALYZE_HAIRCUT_TASK);

// При создании обычной задачи
await this.triggerAiAction(AIAgentAction.ANALYZE_NEW_TASK);

// При изменении статуса на "В работе"
await this.triggerAiAction(AIAgentAction.CHECK_PROGRESS);
```

### Интеллектуальная маршрутизация

Система автоматически определяет, какой AI сервис нужно вызвать на основе:

- Содержимого задачи
- Ключевых слов
- Текущего статуса
- История изменений

## 🚀 Развертывание в продакшен

### 1. Настройка реверс-прокси

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    location /jira/webhook {
        proxy_pass http://localhost:3000;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 2. Мониторинг и алерты

```yaml
# Prometheus alerts
groups:
  - name: webhook-alerts
    rules:
      - alert: WebhookProcessingFailed
        expr: webhook_processing_errors > 5
        annotations:
          summary: 'High webhook processing error rate'
```
