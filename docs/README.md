# Kanban AI Agent 🤖

**Умный AI-агент для анализа стрижек в Jira с автоматической генерацией отчётов**

## 🎯 Что это такое?

Kanban AI Agent - это автоматизированная система, которая:

- 🔍 **Анализирует фотографии стрижек** с помощью Claude 3.5 Sonnet Vision API
- 📊 **Оценивает качество работы** по шкале от 1 до 10
- 📈 **Генерирует аналитические отчёты** с разбивкой по полу, стилям, дням недели
- 🔗 **Интегрируется с Jira** через webhook для автоматической обработки
- 💬 **Добавляет результаты анализа** прямо в комментарии задач

## ⚡ Быстрый старт

### 1. Установка зависимостей

```bash
yarn install
```

### 2. Настройка окружения

```bash
cp .env.example .env
# Заполните переменные в .env файле
```

### 3. Запуск сервера

```bash
yarn start:dev
```

🎉 **Готово!** Сервер запущен на `http://localhost:3000`

## 🚀 Основные возможности

### 🤖 AI Анализ стрижек

- Автоматический анализ фото "до" и "после"
- Оценка качества с детальными комментариями
- Определение пола клиента и стиля стрижки
- Триггер при переводе задачи в статусы: Review, Testing, Done

### 📊 AI Отчёты

- Статистика по количеству стрижек за период
- Анализ качества работы (средние оценки)
- Разбивка по полу клиентов (мужчины/женщины)
- Популярные стили стрижек
- Нагрузка по дням недели
- Поддержка естественного языка: "за сегодня", "за прошлую неделю"

### 🔗 Jira интеграция

- Полное API для управления задачами
- Webhook обработка в реальном времени
- Автоматическое перемещение задач
- Добавление комментариев с результатами анализа

## 📋 Типичный workflow

1. **Создание задачи** в Jira с типом "Сделай стрижку"
2. **Прикрепление фотографий** "до" и "после" работы
3. **Перевод задачи в статус "Review"** → запускается AI анализ
4. **Получение автоматической оценки** и комментария от Claude
5. **Создание отчёта** через задачу для "AI-Report-maker"
6. **Получение аналитики** по всем выполненным работам

## 🛠️ Технологии

- **Backend:** Node.js, NestJS, TypeScript
- **AI:** Claude 3.5 Sonnet Vision API (через OpenRouter)
- **Интеграция:** Jira REST API, Webhook
- **Парсинг дат:** Chrono-node
- **Туннелинг:** ngrok для webhook
