3. **Конфигурация:**
   - Добавлено поле `activeStatuses: ['Review']` в конфигурацию
   - Легко расширить список активных статусов при необходимости

## Эндпойнты

### 1. Основной веб-хук: `POST /jira/webhook`

- Обрабатывает все события Jira
- Активен только для статуса "Review"

### 2. Специализированный веб-хук: `POST /jira/webhook/haircut-tasks`

- Обрабатывает только задачи о стрижках
- Активен только для статуса "Review"

## Логирование

Все события логируются с указанием причины отключения:

- `status-change-disabled` - статус не в списке активных
- `issue-created-logged-only` - создание задачи только логируется
- `comment-logged-only` - комментарий только логируется
- `haircut-status-disabled` - статус отключен для задач о стрижках

## Конфигурационный файл

```typescript
activeStatuses: ['Review'], // Только этот статус будет обрабатываться
```

Чтобы включить другие статусы, добавьте их в этот массив:

```typescript
activeStatuses: ['Review', 'In Progress', 'Done'], // Пример расширения
```

## ✅ Результаты тестирования

Все тесты пройдены успешно:

### Тест 1: Статус "In Progress" (отключен)

```bash
curl -X POST http://localhost:3000/jira/webhook/haircut-tasks -H "x-test-webhook: true" -d '{"issue": {"fields": {"status": {"name": "In Progress"}}}}'
```

**✅ Результат:** `"haircut-status-disabled"` - веб-хук отключен

### Тест 2: Статус "Review" (активен)

```bash
curl -X POST http://localhost:3000/jira/webhook/haircut-tasks -H "x-test-webhook: true" -d '{"issue": {"fields": {"status": {"name": "Review"}}}}'
```

**✅ Результат:** `"review-initiated"` - веб-хук активен

### Тест 3: Основной веб-хук - статус "Done" (отключен)


**✅ Результат:** `"status-change-disabled"` - веб-хук отключен

### Тест 4: Основной веб-хук - статус "Review" (активен)

```bash

```

**✅ Результат:** `"review-initiated", "haircut-review-processing"` - веб-хук активен

### Тест 5: Создание задачи (отключено)


**✅ Результат:** `"issue-created-logged-only"` - только логирование

## Проверка работы

1. Создание новой задачи → веб-хук отключен ✅
2. Переход в To Do → веб-хук отключен ✅
3. Переход в In Progress → веб-хук отключен ✅
4. **Переход в Review → веб-хук активен** ✅
5. Переход в Done → веб-хук отключен ✅
6. Добавление комментария → веб-хук отключен ✅
