# 📸 Photo Analysis - Документация

Папка `photo-analysis` отвечает за анализ фотографий стрижек с помощью Claude AI.

## 📁 Структура папки

- **analyze-before-after-photos** - **ГЛАВНЫЙ**: Анализ фотографий стрижек ДО/ПОСЛЕ через Claude 3.5 Sonnet Vision API

## 🎯 Основная функция

Использует Claude 3.5 Sonnet Vision API для:

- Профессионального анализа качества стрижек
- Оценки работы по шкале 1-10
- Определения пола клиента и типа стрижки
- Генерации детальных рекомендаций
- Возврата структурированного JSON анализа

## 🤖 AI Технологии

- **Claude 3.5 Sonnet** - для анализа изображений
- **OpenRouter API** - для доступа к Claude
- **Base64 encoding** - для передачи изображений
