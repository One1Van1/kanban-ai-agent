# Альтернативы Claude API для тестирования

## 1. OpenAI API (есть бесплатные кредиты)

- $5 бесплатных кредитов при регистрации
- GPT-3.5-turbo дешевле чем Claude

## 2. Google Gemini API

- Часто есть бесплатный tier
- Можно использовать для прототипа

## 3. Локальные модели (бесплатно)

- Ollama с llama3.1
- Работает локально на вашем компьютере

## 4. Оставить fallback логику

- Уже работает без API ключей
- Простая но эффективная логика
- Можно улучшить правила анализа

## Для production рекомендую:

- Начать с fallback
- Протестировать на реальных задачах
- Потом добавить Claude для улучшения качества
