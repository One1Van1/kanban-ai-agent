# get-task-correct

## Описание

Этот файл отвечает за получение детальной информации о задаче.

## Действия

- Получает полную информацию о задаче по ключу
- Извлекает все поля задачи (описание, статус, автор, исполнитель)
- Получает список комментариев
- Показывает прикрепленные файлы
- Форматирует ответ в удобном виде

## API

`GET /jira/tasks/:taskKey`

## Входные данные

- taskKey: ключ задачи в Jira

## Результат

- Полная информация о задаче
- Список комментариев
- Прикрепленные файлы
- Метаданные задачи
