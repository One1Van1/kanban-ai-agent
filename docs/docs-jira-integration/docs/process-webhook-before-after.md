# process-webhook-before-after

## Описание

Этот файл отвечает за автоматический анализ фотографий стрижек через Claude AI.

## Действия

- Обрабатывает webhook события от Jira при изменении статуса
- Проверяет условия для запуска анализа (статус Review + ключевые слова)
- Извлекает фотографии ДО/ПОСЛЕ из прикрепленных файлов
- Отправляет фото на анализ в Claude 3.5 Sonnet Vision API
- Добавляет результат анализа в комментарий к задаче
- Автоматически перемещает задачу в статус Done
- Обрабатывает случаи отсутствия фотографий

## API

`POST /jira/process-webhook-before-after`

## Входные данные

- webhookEvent: тип события от Jira
- issue: данные задачи
- changelog: изменения в задаче

## Результат

- Подтверждение обработки
- Результат Claude анализа
- Статус перемещения задачи
- Детали обработки
