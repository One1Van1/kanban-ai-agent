# 🔗 Jira Integration - Документация

Папка `jira-integration` отвечает за интеграцию с Jira API и обработку задач.

## 📁 Структура папки

- **add-task-comment** - Добавление комментариев к задачам
- **attach-file-correct** - Прикрепление файлов к задачам
- **get-column-tasks-correct** - Получение задач из колонки канбан доски
- **get-task-correct** - Получение детальной информации о задаче
- **get-task-transitions-correct** - Получение доступных переходов задачи
- **health-check-correct** - Проверка работоспособности Jira API
- **jira-webhook-handler-correct** - Обработка общих webhook событий
- **move-task-correct** - Перемещение задач между статусами
- **process-webhook-before-after** - **ГЛАВНЫЙ**: Автоматический анализ фотографий стрижек
- **search-tasks-correct** - Поиск задач по JQL запросам

## 🎯 Основная функция

Обеспечивает полную интеграцию с Jira для автоматизации workflow обработки стрижек с AI анализом.
