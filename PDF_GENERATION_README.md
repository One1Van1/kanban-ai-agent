# 📄 Генерация PDF Презентации

## Что это?

Автоматическая генерация PDF из Markdown презентации архитектуры бэкенда.

## Как использовать?

### Вариант 1: Через Yarn (рекомендуется)

```bash
yarn docs:pdf
```

### Вариант 2: Напрямую через Node

```bash
node generate-pdf.js
```

## Где найти PDF?

После генерации PDF файл будет находиться здесь:

```
kan-back/back-docs/BACKEND_PRESENTATION.pdf
```

## Исходный файл

Markdown презентация:

```
kan-back/back-docs/BACKEND_PRESENTATION.md
```

## Кастомизация стилей

Если нужно изменить оформление PDF, отредактируй файл:

```
pdf-styles.css
```

Там можно настроить:

- Шрифты
- Цвета
- Отступы
- Размеры заголовков
- Стили кодовых блоков

## Требования

- Node.js
- Yarn
- Пакет `markdown-pdf` (уже установлен)
