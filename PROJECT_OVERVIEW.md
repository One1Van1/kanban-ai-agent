# Kanban AI Agent - Основная задача проекта

## Цель проекта

Создать автоматизированную систему для выполнения задач из канбан-доски с помощью AI-агента.

## Описание работы системы

### 1. Триггер события

- Появляется новая задача в канбан-доске
- Система получает уведомление о новой задаче (webhook)

### 2. Анализ задачи AI-агентом

AI-агент анализирует описание задачи и принимает решение на основе:

- Полноты описания задачи
- Наличия всех необходимых деталей для выполнения
- Понятности требований

### 3. Принятие решения

#### Вариант A: Недостаточно информации

**Условие**: Задача содержит неясности, недостаточно деталей или требует дополнительных вопросов
**Действие**: Перемещение задачи в колонку **"Questions"**

#### Вариант B: Задача понятна

**Условие**: Задача имеет четкое описание и достаточно информации для выполнения
**Действие**: Перемещение задачи в колонку **"In Progress"**

### 4. Выполнение задачи

- Если задача находится в колонке "In Progress"
- AI-агент выполняет поставленную задачу
- После завершения выполнения перемещает задачу в колонку **"Review"**

## Архитектура системы

### Основные компоненты:

1. **Webhook Handler** - принимает уведомления от канбан-системы
2. **AI Analysis Engine** - анализирует задачи и принимает решения
3. **Task Executor** - выполняет задачи различных типов
4. **Kanban API Integration** - взаимодействует с канбан-доской
5. **Decision Logic** - координирует процесс принятия решений

## Состояния задач в канбане:

- **New** → Начальное состояние
- **Questions** → Требуют дополнительной информации
- **In Progress** → Выполняются AI-агентом
- **Review** → Завершены и ожидают проверки
