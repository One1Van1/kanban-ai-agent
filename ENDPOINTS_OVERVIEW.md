# 🔌 Обзор эндпойнтов системы

## 🔥 KANBAN-MANAGEMENT ENDPOINTS

### 📥 GET Endpoints (Получение данных)

- Получить детальную информацию о задаче
- Получить все задачи в определенной колонке
- Получить структуру доски (колонки, правила, настройки)
- Получить историю изменений задачи
- Получить все комментарии к задаче
- Получить все задачи назначенные пользователю
- Получить статистику по доске
- Получить обзор проекта

### ➕ POST Endpoints (Создание данных)

- Создать новую задачу
- Создать новую доску
- Создать новую колонку в доске
- Добавить комментарий к задаче
- Назначить задачу пользователю
- Создать новый проект
- Добавить файл к задаче
- Добавить метку к задаче

### 🔄 PUT Endpoints (Полное обновление)

- Полностью обновить задачу
- Полностью обновить доску
- Полностью обновить колонку
- Полностью обновить проект
- Обновить приоритет задачи

### 🔧 PATCH Endpoints (Частичное обновление)

- Переместить задачу в другую колонку
- Изменить статус задачи
- Изменить исполнителя задачи
- Изменить приоритет задачи
- Обновить срок выполнения задачи
- Установить/снять флаг важности

### 🗑️ DELETE Endpoints (Удаление)

- Удалить задачу
- Удалить доску
- Удалить колонку
- Удалить комментарий
- Удалить вложение
- Удалить проект

## 📊 TASK-ANALYTICS ENDPOINTS

### 📥 GET Endpoints (Получение данных)

- Получить метрики продуктивности
- Анализ производительности команды
- Данные для burndown chart
- Анализ времени выполнения задач
- Анализ узких мест в процессе
- Показатели завершения задач

### ➕ POST Endpoints (Создание данных)

- Создать кастомный отчет
- Создать уведомление по метрикам
- Экспортировать данные аналитики
- Настроить регулярные отчеты

---

## 📸 PHOTO-ANALYSIS ENDPOINTS

### ➕ POST Endpoints (Создание данных)

- Анализ скриншота задачи
- Извлечение текста из изображения (OCR)
- Детекция UI элементов на скриншоте
- Сравнение двух изображений
- Генерация отчета по анализу изображений

### 📥 GET Endpoints (Получение данных)

- История анализов изображений
- Поддерживаемые форматы изображений
- Шаблоны для анализа изображений

---

## 🤖 AI-REPORTING ENDPOINTS

### ➕ POST Endpoints (Создание данных)

- AI генерация краткого отчета
- AI анализ инсайтов и рекомендаций
- AI анализ паттернов работы команды
- AI предсказание сроков проекта

- Точность AI предсказаний
- Шаблоны AI отчетов

## 🔌 ENHANCED JIRA-INTEGRATION ENDPOINTS

### 📥 GET Endpoints (Получение данных)

- Конфигурация Jira доски
- Список workflow в Jira
- Кастомные поля Jira
- Роли участников проекта в Jira

### ➕ POST Endpoints (Создание данных)

- Синхронизация данных с Jira
- Создание webhook для Jira
- Импорт истории задач из Jira
- Резервное копирование конфигурации Jira
