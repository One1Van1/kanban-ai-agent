# 📊 AI Reporting - Документация

Папка `ai-reporting` отвечает за генерацию аналитических отчетов по стрижкам.

## 📁 Структура папки

- **generate-report** - Генерация аналитических отчетов по стрижкам
- **get-report-config** - Конфигурация AI агента отчетов
- **get-report-health** - Проверка работоспособности сервиса отчетов
- **process-report-task** - Автоматическая обработка задач с запросами отчетов

## 🎯 Основная функция

Анализирует данные Claude по стрижкам за определенный период и создает подробные отчеты с:

- Статистикой по качеству работ
- Трендами по дням недели
- Разбивкой по полу клиентов и типам стрижек
- Рекомендациями для улучшения
