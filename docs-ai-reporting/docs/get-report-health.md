# get-report-health

## Описание

Этот файл отвечает за проверку работоспособности AI агента отчетов.

## Действия

- Проверяет статус сервиса генерации отчетов
- Возвращает текущее время
- Подтверждает готовность к обработке запросов
- Логирует запросы health check

## API

`GET /ai-reporting/generate-report/health`

## Входные данные

Нет входных параметров

## Результат

- Статус: healthy
- Временная метка проверки
- Название сервиса
