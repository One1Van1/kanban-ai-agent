# analyze-before-after-photos

## Описание

Этот файл отвечает за анализ фотографий стрижек ДО/ПОСЛЕ с помощью Claude 3.5 Sonnet Vision API.

## Действия

- Принимает фотографии в формате base64
- Отправляет запрос к Claude 3.5 Sonnet через OpenRouter
- Анализирует качество стрижки по профессиональным критериям
- Определяет пол клиента и тип стрижки
- Оценивает качество по шкале от 1 до 10
- Генерирует детальные рекомендации
- Возвращает структурированный анализ в JSON формате

## API

`POST /photo-analysis/analyze-before-after`

## Входные данные

- taskKey: ключ задачи
- beforePhoto: фото ДО в base64
- afterPhoto: фото ПОСЛЕ в base64
- declaredCategory: заявленная категория стрижки

## Результат

- Детальный анализ качества стрижки
- Оценка от 1 до 10 баллов
- Определение пола и типа стрижки
- Рекомендации по улучшению
- Уровень уверенности AI в анализе
