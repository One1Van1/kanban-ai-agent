# 🚀 Быстрый тест AI агента через Jira

## ⚡ Быстрый старт (5 минут)

### 1. Запустите проект

```bash
cd /Users/one.van/Desktop/kanban_ai_agent
yarn install
yarn start:dev
```

### 2. Запустите автоматические тесты

```bash
./test-agent.sh
```

### 3. Проверьте ручной сценарий

#### В Jira:

1. Создайте задачу "Стрижка каскад"
2. Прикрепите фото стрижки
3. Переместите в колонку "В работе"

#### Ожидаемый результат:

✅ Автоматически появится комментарий от AI с анализом фото  
✅ Придет уведомление в Telegram  
✅ Задача будет обработана агентом

## 🧪 Ключевые эндпоинты

```bash
# Создание агента
POST /ai-agent

# Настройка инструкций
POST /ai-agent/configure-column-instructions

# Привязка к задаче
POST /ai-agent/track-agent-in-task

# Webhook для автоматизации
POST /jira/webhook

# Мониторинг
GET /ai-agent/activity/{agentId}
```
