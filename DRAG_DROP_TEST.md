# 🧪 Тест Drag & Drop Flow Builder

## Что было улучшено:

### ✅ **1. Правильное позиционирование блоков**

- Использован `useReactFlow` хук с `screenToFlowPosition()`
- Блоки теперь размещаются точно в том месте, где их отпускают
- Учитывается масштабирование и позиция viewport канваса

### ✅ **2. Snap to Grid**

- Добавлено автоматическое выравнивание по сетке 20x20 пикселей
- Работает как при drag & drop, так и при клике на палитру
- Включено в настройки React Flow: `snapToGrid={true}` и `snapGrid={[20, 20]}`

### ✅ **3. Улучшенная визуальная обратная связь**

- **Кастомный drag image**: красивый preview блока при перетаскивании
- **Live preview**: отображение позиции блока в реальном времени на канвасе
- **Анимации**: плавные переходы и эффекты при drag/drop
- **Drop zone**: выделение области сброса с индикацией

### ✅ **4. Обработка edge cases**

- Корректная обработка ошибок парсинга данных
- Проверка границ drop zone
- Правильная очистка drag state

## 📝 Инструкция по тестированию:

1. **Откройте Flow Builder**: http://localhost:3001/agents/flow-builder
2. **Протестируйте drag & drop**:
   - Перетащите любой блок из палитры справа на канвас
   - Блок должен появиться точно там, где вы его отпустили
   - Позиция должна быть выровнена по сетке
3. **Проверьте visual feedback**:
   - При перетаскивании должен показываться preview блока
   - Drop zone должен подсвечиваться
   - Кнопка в палитре должна анимироваться
4. **Тест в разных сценариях**:
   - Попробуйте в разных масштабах (zoom in/out)
   - Перетащите блоки в разные части канваса
   - Проверьте с разными типами блоков

## 🐛 Возможные проблемы:

Если что-то не работает, проверьте:

- Консоль браузера на ошибки JavaScript
- Терминал Next.js на ошибки компиляции
- Правильность импорта `useReactFlow` hook
