## 🚀 Как использовать

### Новый разработчик

1. Начните с [INDEX.md](./INDEX.md)
2. Прочитайте [README.md](./README.md) - архитектура
3. Изучите [Features](./features/README.md) - функционал
4. Посмотрите примеры кода в документах

### Добавление функционала

1. Изучите [Workflow](./README.md#workflow-разработки)
2. Проверьте [Types](./types/README.md) - нужные типы
3. Создайте [Entity](./entities/README.md#создание-новой-сущности)
4. Добавьте [Module](./modules/README.md#создание-нового-модуля)
5. Задокументируйте новый feature

### Поиск информации

1. **По функционалу** → INDEX.md → Features
2. **По API** → Features → Конкретный модуль → Эндпоинты
3. **По типам** → Types → Нужный интерфейс
4. **По настройкам** → Config → Environment variables
