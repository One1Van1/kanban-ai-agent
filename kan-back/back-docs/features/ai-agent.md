# AI Agent

## 🎯 Назначение

Интеллектуальные агенты для автоматизации работы с задачами через AI.

## ⚙️ Возможности

- ✅ Создание агентов с кастомными инструкциями
- ✅ Выполнение задач через AI
- ✅ Запуск агентов на выполнение
- ✅ Получение результатов работы
- ✅ Управление жизненным циклом агентов
- ✅ История выполнения

## 🌐 Эндпоинты

### GET

- `get-agent` - Получить агента по ID
- `get-all-agents` - Список всех агентов
- `get-agent-result` - Результат выполнения агента

### POST

- `create-agent` - Создать нового агента
- `run-agent` - Запустить агента на выполнение

### PATCH

- `update-agent` - Обновить агента

### DELETE

- `delete-agent` - Удалить агента

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение агентов
- `cache-management` - кэширование результатов
- `queue-management` - асинхронное выполнение
- `context-management` - управление контекстом
- `kanban-management` - работа с задачами

**Используется в:**

- `flow-management` - интеграция в флоу
- `ai-reporting` - отчеты по работе агентов
