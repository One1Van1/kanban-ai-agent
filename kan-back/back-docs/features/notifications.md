# Notifications

## 🎯 Назначение

Система уведомлений для информирования пользователей о событиях в системе.

## ⚙️ Возможности

- ✅ Отправка уведомлений
- ✅ Управление подписками
- ✅ Различные каналы (email, push, in-app)
- ✅ Шаблоны уведомлений
- ✅ История уведомлений
- ✅ Настройки предпочтений

## 🌐 Эндпоинты

### GET

- `get-notifications` - Получить уведомления пользователя
- `get-notification-settings` - Настройки уведомлений

### POST

- `send-notification` - Отправить уведомление
- `mark-as-read` - Отметить как прочитанное

### PATCH

- `update-notification-settings` - Обновить настройки

### DELETE

- `delete-notification` - Удалить уведомление

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение уведомлений
- `cache-management` - кэширование настроек
- `queue-management` - асинхронная отправка

**Используется в:**

- `kanban-management` - уведомления о задачах
- `ai-agent` - уведомления о выполнении
- `jira-integration` - уведомления о синхронизации
- `flow-management` - уведомления о флоу
