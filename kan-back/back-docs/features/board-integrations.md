# Board Integrations

## 🎯 Назначение

Интеграции с различными системами управления задачами (Trello, Asana, Monday и др.).

## ⚙️ Возможности

- ✅ Подключение к различным платформам
- ✅ Универсальный адаптер
- ✅ Двусторонняя синхронизация
- ✅ Маппинг полей
- ✅ Конфликт-резолюшн
- ✅ Batch операции

## 🌐 Эндпоинты

### GET

- `get-integrations` - Список подключенных интеграций
- `get-integration-status` - Статус интеграции

### POST

- `connect-board` - Подключить доску
- `sync-board` - Синхронизировать доску
- `import-from-board` - Импорт с доски

### DELETE

- `disconnect-board` - Отключить интеграцию

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение настроек
- `cache-management` - кэширование данных
- `kanban-management` - работа с задачами
- `queue-management` - асинхронная синхронизация

**Используется в:**

- `jira-integration` - часть общей системы интеграций
- `ai-reporting` - аналитика по интеграциям
