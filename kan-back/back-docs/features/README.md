## 🏗️ Архитектура

### Структура feature-блока

Каждый feature-блок организован по методам HTTP:

```
feature-name/
├── GET/           # Эндпоинты для получения данных
├── POST/          # Эндпоинты для создания
├── PATCH/         # Эндпоинты для обновления
├── DELETE/        # Эндпоинты для удаления
└── feature-name.module.ts
```

### Структура эндпоинта

Каждый эндпоинт - это отдельная папка:

```
endpoint-name/
├── endpoint-name.controller.ts
├── endpoint-name.service.ts
├── endpoint-name.dto.ts
├── endpoint-name.module.ts
├── endpoint-name.interface.ts
└── endpoint-name.spec.ts
```

## 📝 Соглашения по документации

Каждый документ feature-модуля содержит:

1. **🎯 Назначение** - краткое описание цели модуля
2. **⚙️ Возможности** - список основных функций
3. **🌐 Эндпоинты** - структурированный список API endpoints
4. **🔌 Интеграции** - связи с другими модулями

## 🚀 Начало работы

1. Выберите нужный модуль из списка выше
2. Откройте соответствующий файл документации
3. Изучите доступные эндпоинты и возможности
4. Проверьте зависимости модуля

## 🔍 Поиск информации

- **По функционалу**: используйте раздел "Возможности" в каждом документе
- **По API**: смотрите раздел "Эндпоинты"
- **По связям**: изучайте раздел "Интеграции"

## 📦 Package Manager

**⚠️ ВАЖНО: Всегда используйте YARN, никогда NPM!**

```bash
# Установка зависимостей
yarn install

# Добавление пакета
yarn add package-name

# Запуск проекта
yarn start:dev
```

## 🤝 Вклад в документацию

При добавлении нового feature-модуля:

1. Создайте файл `feature-name.md` по шаблону существующих
2. Добавьте ссылку в этот README
3. Обновите диаграмму зависимостей при необходимости
4. Следуйте структуре: Назначение → Возможности → Эндпоинты → Интеграции
