# Queue Management

## 🎯 Назначение

Управление очередями для асинхронной обработки задач.

## ⚙️ Возможности

- ✅ Асинхронная обработка задач
- ✅ BullMQ интеграция
- ✅ Приоритизация задач
- ✅ Retry механизм
- ✅ Dead letter queue
- ✅ Мониторинг очередей

## 🌐 Функционал

### Основные возможности

- Отложенное выполнение
- Планирование задач (cron)
- Обработка в фоне
- Масштабирование workers
- Отслеживание прогресса

## 🔌 Интеграции

**Использует:**

- BullMQ - система очередей
- Redis - хранилище очередей

**Используется в:**

- `ai-agent` - асинхронное выполнение агентов
- `flow-management` - выполнение флоу в фоне
- `jira-integration` - синхронизация в фоне
- `ai-reporting` - генерация отчетов
- `photo-analysis` - анализ изображений
- `notifications` - отправка уведомлений
