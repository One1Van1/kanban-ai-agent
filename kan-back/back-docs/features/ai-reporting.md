# AI Reporting

## 🎯 Назначение

Аналитика и отчеты по работе системы с использованием AI.

## ⚙️ Возможности

- ✅ Генерация отчетов через AI
- ✅ Анализ продуктивности
- ✅ Статистика по задачам
- ✅ Аналитика работы агентов
- ✅ Insights и рекомендации
- ✅ Экспорт отчетов

## 🌐 Эндпоинты

### GET

- `get-report` - Получить отчет
- `get-analytics-summary` - Сводка по аналитике
- `get-productivity-stats` - Статистика продуктивности

### POST

- `generate-report` - Сгенерировать отчет через AI
- `analyze-tasks` - Анализ задач
- `get-insights` - Получить insights

## 🔌 Интеграции

**Использует:**

- `database-management` - данные для анализа
- `cache-management` - кэширование отчетов
- `kanban-management` - данные по задачам
- `ai-agent` - данные по агентам
- `context-management` - контекст для AI

**Используется в:**

- Клиентские приложения для отображения аналитики
