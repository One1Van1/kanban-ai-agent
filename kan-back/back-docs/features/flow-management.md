# Flow Management

## 🎯 Назначение

Визуальный конструктор потоков (flow builder) для создания автоматизированных процессов.

## ⚙️ Возможности

- ✅ CRUD операции с флоу
- ✅ Конвертация флоу в агентов
- ✅ Выполнение флоу
- ✅ Управление блоками и связями
- ✅ Валидация структуры флоу
- ✅ История выполнения

## 🌐 Эндпоинты

### GET

- `get-flow` - Получить флоу по ID
- `get-all-flows` - Список всех флоу
- `get-flow-result` - Результат выполнения флоу

### POST

- `create-flow` - Создать новый флоу
- `run-flow` - Запустить флоу на выполнение
- `convert-flow-to-agent` - Конвертировать флоу в агента

### PATCH

- `update-flow` - Обновить флоу

### DELETE

- `delete-flow` - Удалить флоу

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение флоу
- `cache-management` - кэширование
- `queue-management` - асинхронное выполнение
- `flow-conversion` - конвертация в агентов
- `ai-agent` - создание агентов из флоу

**Используется в:**

- `ai-reporting` - аналитика по флоу
- `kanban-management` - автоматизация задач
