# Context Management

## 🎯 Назначение

Управление контекстом для AI моделей и агентов.

## ⚙️ Возможности

- ✅ Создание и хранение контекста
- ✅ Управление историей диалогов
- ✅ Оптимизация размера контекста
- ✅ Приоритизация информации
- ✅ Автоматическая очистка
- ✅ Версионирование контекста

## 🌐 Функционал

### Основные возможности

- Сохранение состояния AI
- Управление памятью агентов
- Контекстные окна
- Релевантная информация
- История взаимодействий

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение контекста
- `cache-management` - быстрый доступ

**Используется в:**

- `ai-agent` - контекст для агентов
- `flow-management` - контекст флоу
- `ai-reporting` - контекст для аналитики
- `photo-analysis` - контекст анализа
