# Photo Analysis

## 🎯 Назначение

Анализ изображений и фотографий через AI для автоматизации работы с визуальным контентом.

## ⚙️ Возможности

- ✅ Загрузка и анализ изображений
- ✅ Распознавание объектов
- ✅ Извлечение текста (OCR)
- ✅ Генерация описаний
- ✅ Классификация изображений
- ✅ Создание задач на основе анализа

## 🌐 Эндпоинты

### POST

- `analyze-photo` - Анализ фотографии через AI
- `upload-and-analyze` - Загрузка и анализ
- `create-task-from-photo` - Создать задачу из фото

### GET

- `get-analysis-result` - Результат анализа

## 🔌 Интеграции

**Использует:**

- `database-management` - хранение результатов
- `cache-management` - кэширование анализа
- `kanban-management` - создание задач
- `context-management` - контекст для AI

**Используется в:**

- `ai-agent` - автоматизация через фото
- `flow-management` - интеграция в флоу
