# jira-time-logger.service.ts

## Описание
Этот файл отвечает за автоматическое логирование времени работы AI агента.

## Действия
- Логирует время выполнения AI анализа в Jira worklog
- Автоматически рассчитывает время работы в секундах
- Добавляет метку "🤖 AI Agent" к записям времени
- Устанавливает текущее время как время начала работы
- Обрабатывает ошибки логирования времени

## API методы
- logWorkTime() - логирование времени с комментарием
- calculateProcessingTime() - расчет времени обработки
- formatTimeLog() - форматирование записи времени

## Входные данные
- issueKey: ключ задачи
- timeSpentMinutes: время в минутах
- comment: описание выполненной работы

## Результат
- Автоматические записи времени в Jira
- Отслеживание производительности AI агента
- Аналитика времени обработки задач
