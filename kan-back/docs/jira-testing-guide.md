# 🧪 Руководство по тестированию AI агента через Jira

## 📋 Обзор

Данное руководство поможет вам протестировать функциональность AI агента через Jira интеграцию, включая все возможности, описанные в техническом задании.

## 🎯 Что нужно проверить (согласно скриншоту)

### 1. **Гибкая настройка AI агента**

- Возможность добавления агента в задачу и отслеживания его работы
- Установка инструкций для выполнения при попадании карточки в определенную колонку
- Настройка действий с карточкой в какой-то колонке

### 2. **Выбор контекста**

- Получение контекста из карточки
- Получение из других карточек по критериям
- Получение из внешних источников (БД и т.д.)

### 3. **Полная логика с тестами**

- 100% покрытие тестами
- Реальные тесты, а не заглушки

### 4. **Работа в очередях**

- Уведомления в Telegram

### 5. **Удобный сайт-конструктор**

- Создание агентов и настройка их поведения

### 6. **Интеграция с Jira**

- Замена клиента на любую другую систему
- Сервисы-адаптеры для получения данных о карточке

## 🛠️ Подготовка к тестированию

### Шаг 1: Запуск проекта

```bash
cd /Users/one.van/Desktop/kanban_ai_agent
yarn install
yarn start:dev
```

### Шаг 2: Настройка Jira

1. Убедитесь, что у вас есть доступ к Jira проекту
2. Настройте webhook в Jira для отправки событий в ваше приложение
3. Создайте тестовую канбан доску с колонками: To Do, In Progress, Review, Done

### Шаг 3: Настройка окружения

Проверьте конфигурацию в `.env`:

```
JIRA_HOST=your-jira-instance.atlassian.net
JIRA_EMAIL=your-email@domain.com
JIRA_API_TOKEN=your-api-token
JIRA_PROJECT_KEY=TEST
```

## 🧪 Сценарии тестирования

### Тест 1: Создание и настройка AI агента

#### 1.1 Создание агента

```bash
curl -X POST http://localhost:3000/ai-agent \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Тестовый AI агент",
    "description": "Агент для автоматической обработки задач",
    "type": "task_processor",
    "configuration": {
      "model": "claude-3",
      "temperature": 0.7
    }
  }'
```

**Ожидаемый результат:** Агент создан, получен ID агента

#### 1.2 Настройка инструкций для колонки

```bash
curl -X POST http://localhost:3000/ai-agent/configure-column-instructions \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent-id-from-step-1",
    "columnId": "in-progress",
    "instructions": "При попадании задачи в колонку In Progress, проанализируй описание задачи и добавь комментарий с планом выполнения"
  }'
```

**Ожидаемый результат:** Инструкции сохранены для колонки

### Тест 2: Интеграция с Jira - Перемещение задачи

#### 2.1 Создание задачи в Jira

1. Зайдите в ваш Jira проект
2. Создайте новую задачу с типом "Story"
3. Добавьте описание: "Тестовая задача для проверки AI агента"
4. Поместите задачу в колонку "To Do"

#### 2.2 Привязка агента к задаче

```bash
curl -X POST http://localhost:3000/ai-agent/track-agent-in-task \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "agent-id-from-test-1",
    "taskId": "TASK-123",
    "projectKey": "TEST"
  }'
```

**Ожидаемый результат:** Агент привязан к задаче

#### 2.3 Перемещение задачи в колонку "In Progress"

В Jira переместите задачу из "To Do" в "In Progress"

**Ожидаемый результат:**

- Webhook срабатывает
- AI агент получает уведомление
- Агент выполняет настроенные инструкции
- В задачу добавляется комментарий с планом выполнения

### Тест 3: Работа с контекстом

#### 3.1 Получение контекста из карточки

```bash
curl -X GET http://localhost:3000/jira/task/TASK-123 \
  -H "Content-Type: application/json"
```

**Ожидаемый результат:** Полная информация о задаче

#### 3.2 Поиск связанных задач

```bash
curl -X POST http://localhost:3000/jira/search \
  -H "Content-Type: application/json" \
  -d '{
    "jql": "project = TEST AND status = \"In Progress\"",
    "maxResults": 10
  }'
```

**Ожидаемый результат:** Список связанных задач

### Тест 4: Выполнение действий агента

#### 4.1 Добавление комментария

```bash
curl -X POST http://localhost:3000/jira/task/TASK-123/comment \
  -H "Content-Type: application/json" \
  -d '{
    "comment": "AI агент проанализировал задачу. План выполнения: 1) Анализ требований 2) Разработка 3) Тестирование"
  }'
```

**Ожидаемый результат:** Комментарий добавлен в Jira

#### 4.2 Прикрепление файла

```bash
curl -X POST http://localhost:3000/jira/task/TASK-123/attachment \
  -H "Content-Type: multipart/form-data" \
  -F "file=@test-document.pdf"
```

**Ожидаемый результат:** Файл прикреплен к задаче

### Тест 5: Проверка здоровья системы

#### 5.1 Health Check Jira

```bash
curl -X GET http://localhost:3000/jira/health
```

**Ожидаемый результат:** Статус подключения к Jira

#### 5.2 Получение активности агента

```bash
curl -X GET http://localhost:3000/ai-agent/activity/agent-id-from-test-1
```

**Ожидаемый результат:** История действий агента

## 🚨 Возможные проблемы и решения

### Проблема: Webhook не срабатывает

**Решение:**

1. Проверьте настройки webhook в Jira
2. Убедитесь, что URL доступен извне (используйте ngrok)
3. Проверьте логи Jira для ошибок webhook'ов

### Проблема: Агент не выполняет действия

**Решение:**

1. Проверьте привязку агента к задаче
2. Убедитесь в корректности инструкций
3. Проверьте статус агента

### Проблема: Ошибки аутентификации Jira

**Решение:**

1. Проверьте API токен
2. Убедитесь в корректности email
3. Проверьте права доступа к проекту
