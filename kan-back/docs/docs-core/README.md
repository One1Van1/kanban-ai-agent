# 🚀 Core - Документация

Папка с основными файлами приложения в корне `src/`.

## 📁 Структура папки

- **app.controller.ts** - Главный контроллер приложения
- **app.service.ts** - Главный сервис приложения  
- **app.module.ts** - Корневой модуль NestJS
- **main.ts** - Точка входа в приложение

## 🎯 Основная функция

Инициализация и настройка:
- **Bootstrapping** NestJS приложения
- **Подключение модулей** (AI Reporting, Jira Integration, Photo Analysis)
- **Настройка middleware** и глобальных настроек
- **Конфигурация Swagger** документации
- **Запуск HTTP сервера**

## 🏗️ Архитектура

Следует принципам NestJS:
- Модульная архитектура
- Dependency Injection
- Декораторы для конфигурации
- Автоматическая загрузка компонентов
