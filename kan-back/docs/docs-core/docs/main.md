# main.ts

## Описание
Этот файл отвечает за инициализацию и запуск NestJS приложения.

## Действия
- Создает экземпляр NestJS приложения
- Настраивает body-parser для обработки больших webhook (50MB лимит)
- Обрабатывает webhook на корневом пути и перенаправляет на правильные эндпоинты
- Настраивает CORS для разработки
- Конфигурирует Swagger API документацию
- Включает глобальную валидацию входящих данных
- Запускает HTTP сервер на указанном порту

## Настройки
- **Body Parser**: лимит 50MB для больших изображений
- **CORS**: включен для всех доменов
- **Swagger**: доступен по адресу /api
- **Validation**: автоматическая валидация DTO
- **Port**: из переменной окружения PORT (по умолчанию 3000)

## Middleware
- Перехват webhook на корневом пути
- Логирование размера входящих данных
- Автоматическое перенаправление на правильные эндпоинты

## Результат
- Полностью настроенный HTTP сервер
- Готовность к обработке Jira webhook
- API документация в Swagger
