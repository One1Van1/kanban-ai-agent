# app.module.ts

## Описание
Этот файл отвечает за корневой модуль NestJS приложения.

## Действия
- Импортирует и настраивает ConfigModule с глобальным доступом
- Загружает конфигурации (app, jira, claude) из переменных окружения
- Подключает основные модули приложения с автозагрузкой
- Регистрирует главный контроллер и сервис
- Организует архитектуру приложения по доменам

## Подключенные модули
- **JiraIntegrationModule** - все интеграции с Jira API
- **PhotoAnalysisModule** - анализ фотографий через Claude
- **AiReportingModule** - генерация AI отчетов и аналитики

## Конфигурация
- **isGlobal: true** - конфигурация доступна во всех модулях
- **envFilePath: '.env'** - загрузка переменных из .env файла
- **load: [configs]** - автоматическая загрузка типизированных конфигураций

## Результат
- Полностью настроенный корневой модуль
- Модульная архитектура с автозагрузкой
- Глобальный доступ к конфигурации
