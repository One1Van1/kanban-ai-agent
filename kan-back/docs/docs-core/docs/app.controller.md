# app.controller.ts

## Описание
Этот файл отвечает за главный контроллер приложения на корневом пути.

## Действия
- Обрабатывает GET запрос на корневой путь "/"
- Возвращает приветственное сообщение через AppService
- Служит точкой входа для проверки работоспособности

## API
`GET /` - приветственная страница приложения

## Входные данные
Нет входных параметров

## Результат
- Приветственное сообщение
- Подтверждение работы сервера
- Базовая точка для health check
