# generate-report

## Описание

Этот файл отвечает за генерацию аналитических отчетов по стрижкам.

## Действия

- Парсит период дат из описания задачи
- Ищет все задачи со стрижками за указанный период
- Извлекает Claude анализы из комментариев задач
- Рассчитывает статистику по качеству, полу клиентов, стилям стрижек
- Анализирует тренды по дням недели и времени
- Генерирует рекомендации на основе данных
- Форматирует итоговый отчет с графиками и выводами

## API

`POST /ai-reporting/generate-report`

## Входные данные

- taskKey: ключ задачи с запросом отчета
- dateRange: период для анализа (например, "за прошлую неделю")

## Результат

- Подробная статистика по стрижкам
- Анализ качества работ
- Тренды и рекомендации
