# get-report-config

## Описание

Этот файл отвечает за предоставление конфигурации AI агента отчетов.

## Действия

- Возвращает поддерживаемые форматы дат для отчетов
- Показывает доступные типы отчетов
- Предоставляет настройки по умолчанию
- Отображает примеры использования

## API

`GET /ai-reporting/generate-report/config`

## Входные данные

Нет входных параметров

## Результат

- Список поддерживаемых форматов дат
- Период по умолчанию (7 дней)
- Доступные типы анализа
- Примеры запросов
