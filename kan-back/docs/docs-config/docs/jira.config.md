# jira.config.ts

## Описание
Этот файл отвечает за конфигурацию Jira API и маппинг статусов.

## Действия
- Регистрирует настройки подключения к Jira
- Устанавливает базовый URL Jira инстанса
- Настраивает аутентификацию (email + API token)
- Определяет ключ проекта по умолчанию
- Маппирует статусы канбан доски для автоматизации

## Переменные окружения
- JIRA_BASE_URL: URL Jira инстанса
- JIRA_EMAIL: email для аутентификации
- JIRA_API_TOKEN: API токен Jira
- JIRA_PROJECT_KEY: ключ проекта
- JIRA_STATUS_*: названия статусов для маппинга

## Результат
- Полная конфигурация Jira интеграции
- Маппинг статусов для автоматического движения задач
- Безопасная аутентификация через API токены
