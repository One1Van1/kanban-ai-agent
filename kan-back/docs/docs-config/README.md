# ⚙️ Config - Документация

Папка `config` отвечает за конфигурацию приложения и внешних сервисов.

## 📁 Структура папки

- **app.config.ts** - Основная конфигурация приложения
- **claude.config.ts** - Конфигурация Claude AI API
- **jira.config.ts** - Конфигурация Jira API
- **index.ts** - Экспорт всех конфигураций

## 🎯 Основная функция

Централизованное управление всеми настройками приложения через переменные окружения:
- Порт сервера
- API ключи
- URL сервисов
- Маппинг статусов Jira
- Параметры AI модели
