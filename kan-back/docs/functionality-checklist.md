# 🎯 Пошаговая проверка функциональности AI агента

## 📸 Основываясь на требованиях со скриншота

### ✅ 1. Гибкая настройка AI агента

#### Что проверяем:

- ✅ Можно добавить агента в задачу и отслеживать его работу
- ✅ Можно установить инструкции для выполнения при попадании карточки в колонку
- ✅ Можно настроить действия с карточкой в конкретной колонке

#### Как проверить:

**Шаг 1.1:** Создайте агента

```bash
curl -X POST http://localhost:3000/ai-agent \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Парикмахер AI",
    "description": "Анализирует фото стрижек и дает рекомендации",
    "type": "hairdressing_expert"
  }'
```

**Шаг 1.2:** Настройте инструкции для колонки "В работе"

```bash
curl -X POST http://localhost:3000/ai-agent/configure-column-instructions \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "{AGENT_ID}",
    "columnId": "in-progress",
    "instructions": "Когда задача попадает в колонку В работе: 1) Проанализируй все фото 2) Добавь комментарий с рекомендациями 3) Оцени сложность от 1 до 10"
  }'
```

**Шаг 1.3:** Привяжите агента к задаче

```bash
curl -X POST http://localhost:3000/ai-agent/track-agent-in-task \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "{AGENT_ID}",
    "taskId": "HAIR-123"
  }'
```

**✅ Результат:** Агент привязан к задаче, инструкции настроены

## 🧪 Полный сценарий проверки (5 минут)

### Быстрая проверка всей функциональности:

```bash
#!/bin/bash

echo "🚀 Начинаем проверку AI агента..."

# 1. Создание агента
echo "1️⃣ Создаем агента..."
AGENT_RESPONSE=$(curl -s -X POST http://localhost:3000/ai-agent \
  -H "Content-Type: application/json" \
  -d '{"name": "Тестовый агент", "type": "test"}')
AGENT_ID=$(echo $AGENT_RESPONSE | jq -r '.id')
echo "✅ Агент создан: $AGENT_ID"

# 2. Настройка инструкций
echo "2️⃣ Настраиваем инструкции..."
curl -s -X POST http://localhost:3000/ai-agent/configure-column-instructions \
  -H "Content-Type: application/json" \
  -d "{\"agentId\": \"$AGENT_ID\", \"columnId\": \"in-progress\", \"instructions\": \"Тестовые инструкции\"}"
echo "✅ Инструкции настроены"

# 3. Проверка здоровья
echo "3️⃣ Проверяем здоровье системы..."
curl -s http://localhost:3000/jira/health | jq '.status'
echo "✅ Система работает"

# 4. Запуск тестов
echo "4️⃣ Запускаем тесты..."
yarn test --silent
echo "✅ Тесты прошли"

# 5. Проверка очереди
echo "5️⃣ Проверяем очередь..."
curl -s http://localhost:3000/queue/status | jq '.active'
echo "✅ Очередь работает"

echo "🎉 Все проверки пройдены успешно!"
```

Сохраните как `quick-test.sh` и запустите:

```bash
chmod +x quick-test.sh
./quick-test.sh
```
