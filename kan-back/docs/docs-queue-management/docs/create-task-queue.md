# create-task-queue

## Описание

Этот файл отвечает за добавление задач в очередь для фоновой обработки.

## Действия

- Проверяет валидность данных задачи
- Добавляет задачу в Bull Queue
- Настраивает приоритет и задержку
- Логирует добавление в очередь
- Обрабатывает ошибки очереди

## API

`POST /queue/tasks`

## Входные данные

- type: тип задачи
- payload: данные для обработки
- priority: приоритет выполнения (опционально)
- delay: задержка выполнения (опционально)

## Результат

- jobId: уникальный идентификатор задачи
- success: статус добавления
- message: описание результата
