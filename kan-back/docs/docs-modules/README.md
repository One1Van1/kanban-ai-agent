# 🧩 Modules - Документация

Папка `modules` отвечает за основные модули приложения.

## 📁 Структура папки

- **ai-agent.module.ts** - Модуль управления AI агентами
- **ai-reporting.module.ts** - Модуль AI отчетов и аналитики
- **jira-integration.module.ts** - Модуль интеграции с Jira
- **notifications.module.ts** - Модуль системы уведомлений
- **photo-analysis.module.ts** - Модуль анализа фотографий
- **queue-management.module.ts** - Модуль управления очередями задач

## 🎯 Основная функция

Организует приложение по доменам:

- **AI агенты** - создание и управление AI агентами
- **AI отчеты** - генерация аналитических отчетов
- **Jira интеграция** - работа с задачами и webhook
- **Уведомления** - отправка email и telegram уведомлений
- **Анализ фото** - обработка изображений через Claude AI
- **Очереди** - фоновая обработка задач через Bull Queue

## 🏗️ Архитектура

Каждый модуль использует авто-загрузку контроллеров и сервисов из соответствующих папок в `features/`.
