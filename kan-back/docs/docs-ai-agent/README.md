# 🤖 AI Agent - Документация

Папка `ai-agent` отвечает за управление AI агентами в системе Kanban.

## 📁 Структура папки

- **create-agent** - Создание новых AI агентов
- **configure-agent** - Настройка параметров и инструкций агентов
- **track-agent-in-task** - Привязка агентов к конкретным задачам

## 🎯 Основная функция

Обеспечивает полный жизненный цикл AI агентов: создание, настройку и отслеживание их работы с задачами.
