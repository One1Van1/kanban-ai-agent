# configure-agent

## Описание

Этот файл отвечает за настройку параметров и инструкций существующих AI агентов.

## Действия

- Проверяет существование агента
- Обновляет конфигурацию агента
- Поддерживает частичное обновление
- Логирует изменения
- Обрабатывает ошибки настройки

## API

`PUT /ai-agent/:agentId/configure`

## Входные данные

- agentId: идентификатор агента (в URL)
- name: новое имя (опционально)
- instructions: обновленные инструкции (опционально)
- enabled: статус активности (опционально)

## Результат

- success: статус обновления
- agentId: идентификатор агента
- message: описание результата
