# track-agent-in-task

## Описание

Этот файл отвечает за привязку AI агентов к конкретным задачам для отслеживания.

## Действия

- Проверяет существование агента
- Проверяет доступность задачи
- Создает связь агент-задача
- Настраивает отслеживание событий
- Логирует начало отслеживания

## API

`POST /ai-agent/track-agent-in-task/:agentId`

## Входные данные

- agentId: идентификатор агента (в URL)
- taskKey: ключ задачи в системе
- trackingConfig: конфигурация отслеживания (опционально)

## Результат

- success: статус привязки
- trackingId: идентификатор отслеживания
- message: описание результата
