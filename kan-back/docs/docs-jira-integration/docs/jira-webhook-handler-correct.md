# jira-webhook-handler-correct

## Описание

Этот файл отвечает за обработку общих webhook событий от Jira.

## Действия

- Принимает webhook события от Jira
- Парсит JSON данные события
- Определяет тип события (создание, обновление, удаление)
- Логирует входящие события
- Маршрутизирует события к специализированным обработчикам

## API

`POST /jira/webhook`

## Входные данные

- webhookEvent: тип события
- issue: данные задачи
- user: информация о пользователе
- changelog: изменения в задаче

## Результат

- Подтверждение получения webhook
- Статус обработки
- Информация о переданном событии
