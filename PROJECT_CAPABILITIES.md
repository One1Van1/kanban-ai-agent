# 🎯 AI Kanban Agent - Возможности Проекта

## 🌐 Фронтенд (localhost:3001)

### 📱 Доступные Страницы:

#### 🏠 Главная страница (/)

- **URL:** http://localhost:3001/
- **Возможности:**
  - 🎨 Красивый landing page с градиентным дизайном
  - 📊 Обзор статистики проекта
  - 🔗 Навигация к основным разделам
  - 📋 Карточки с метриками (задачи, агенты, активность)

#### 🤖 Страница Агентов (/agents)

- **URL:** http://localhost:3001/agents
- **Возможности:**
  - 📋 Список всех AI агентов
  - ⚡ Статус агентов (активные/неактивные)
  - 🎛️ Управление агентами (старт/стоп)
  - ➕ Создание новых агентов
  - 🔧 Настройки агентов

#### ➕ Создание Агента (/agents/create)

- **URL:** http://localhost:3001/agents/create
- **Возможности:**
  - 🛠️ Форма создания нового AI агента
  - ⚙️ Настройка параметров агента
  - 🎯 Выбор типа агента и его функций

#### 🔗 Flow Builder (/agents/flow-builder)

- **URL:** http://localhost:3001/agents/flow-builder
- **Возможности:**
  - 🎨 Визуальный конструктор workflow
  - 🔄 Создание автоматизированных процессов
  - 📊 Настройка правил и условий

#### 📋 Kanban Доски (/kanban)

- **URL:** http://localhost:3001/kanban
- **Возможности:**
  - 📌 Просмотр всех досок
  - 📊 Статистика по доскам
  - 👥 Информация об активных агентах
  - 📈 Метрики задач

## 🏗️ Бэкенд API (localhost:3000)

### 📚 API Документация:

- **Swagger UI:** http://localhost:3000/api
- **API Base:** http://localhost:3000/api/

### 🎯 Основные Модули:

#### 🤖 AI Agent Module

- **Эндпоинты для управления AI агентами**
- Создание, настройка, запуск агентов

#### 📋 Kanban Management Module

- **GET эндпоинты:**
  - `GET /kanban/task-details` - Детали задачи
  - `GET /kanban/tasks-by-column` - Задачи по колонкам
  - `GET /kanban/board-structure` - Структура доски

- **POST эндпоинты:**
  - `POST /kanban/create-task` - Создание задачи
  - `POST /kanban/assign-task` - Назначение задачи
  - `POST /kanban/add-task-comment` - Добавление комментария

- **PATCH эндпоинты:**
  - `PATCH /kanban/change-task-status` - Изменение статуса
  - `PATCH /kanban/update-task` - Обновление задачи

- **DELETE эндпоинты:**
  - `DELETE /kanban/delete-board` - Удаление доски
  - `DELETE /kanban/delete-task` - Удаление задачи

#### 🔗 Jira Integration Module

- **Интеграция с Jira**
- Синхронизация задач
- Импорт/экспорт данных

#### 📊 AI Reporting Module

- **Аналитика и отчеты**
- Метрики производительности
- AI-powered insights

#### 📸 Photo Analysis Module

- **Анализ изображений**
- AI обработка фото
- Извлечение данных из изображений

#### 🔔 Notifications Module

- **Система уведомлений**
- Email, push уведомления
- Настройка правил

#### 🗄️ Database Management

- **PostgreSQL интеграция**
- Управление данными
- Миграции

#### 🚦 Queue Management

- **Redis + Bull очереди**
- Асинхронная обработка
- Фоновые задачи

## 🎯 Что можно делать прямо сейчас:

### ✅ Готово к использованию:

1. **Просматривать интерфейс** - красивый UI готов
2. **Изучать API** - Swagger документация доступна
3. **Тестировать эндпоинты** - все API работают
4. **Создавать агентов** - форма готова
5. **Управлять досками** - базовый функционал есть

### 🔄 Требует доработки:

1. **Подключение фронтенда к API** - нужно связать UI с бэкендом
2. **Реальные данные** - сейчас используются mock данные
3. **Аутентификация** - система авторизации
4. **Real-time обновления** - WebSocket интеграция

## 🚀 Команды для тестирования:

```bash
# Открыть фронтенд
open http://localhost:3001

# Открыть API документацию
open http://localhost:3000/api

# Проверить статус
make status

# Перезапустить
make stop && make start
```
