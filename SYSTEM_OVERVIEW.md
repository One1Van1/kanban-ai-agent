# 📊 Краткий обзор системы Kanban AI Agent

## 🎯 Основные компоненты системы

### 🤖 **Создание и управление AI агентами** ⭐ ENHANCED!

- **Код:** `src/modules/ai-agent.module.ts` + `src/features/ai-agent/`
- **Функция:** Создание, настройка и выполнение действий AI агентов
- **Эндпоинты:** 6 основных + 12 новых интеллектуальных
- **🧠 Новые возможности:**
  - **IntelligentAgentService** - многоуровневый анализ и принятие решений
  - **KanbanKnowledgeBaseService** - база знаний канбан-процессов
  - **AgentLearningService** - система обучения и анализа производительности
  - **AgentRoleService** - 8 специализированных ролей агентов
  - **Система ролей:** workflow_optimizer, quality_controller, priority_manager, stakeholder_communicator, resource_allocator, risk_assessor, performance_analyst, universal

### 🗄️ **База данных с PostgreSQL**

- **Код:** `src/modules/database.module.ts` + `src/modules/database-management.module.ts`
- **Функция:** Хранение конфигураций агентов, истории задач, логов
- **Сущности:** Agent, AgentInstruction, TaskHistory, NotificationLog

### 🔄 **Система очередей на Redis/Bull**

- **Код:** `src/modules/queue-management.module.ts` + Bull Queue процессоры
- **Функция:** Фоновая обработка задач, управление очередями
- **Возможности:** Создание, статус, детали задач в очереди

### 🎯 **Интеграция с Jira**

- **Код:** `src/modules/jira-integration.module.ts` + 11 эндпоинтов
- **Функция:** Полная работа с Jira (задачи, комментарии, файлы, webhook)
- **Эндпоинты:** add-comment, get-task, move-task, search-tasks, health-check и др.

### ⚡ **Redis кеширование**

- **Код:** `src/modules/cache-management.module.ts`
- **Функция:** Оптимизация производительности через кеширование
- **Возможности:** Cache context, agent configs, cached context

### 🧠 **Контекстное управление**

- **Код:** `src/modules/context-management.module.ts`
- **Функция:** Управление контекстом для AI агентов
- **Эндпоинты:** configure-sources, fetch-context, related-tasks, external-context

### 📊 **AI отчеты и аналитика**

- **Код:** `src/modules/ai-reporting.module.ts`
- **Функция:** Генерация аналитических отчетов с Claude AI
- **Возможности:** Генерация отчетов, конфигурация, health-check, обработка задач

### 🔔 **Система уведомлений**

- **Код:** `src/modules/notifications.module.ts`
- **Функция:** Отправка уведомлений через Email и Telegram
- **Эндпоинты:** send-email, send-telegram

### 📸 **Анализ фотографий**

- **Код:** `src/modules/photo-analysis.module.ts`
- **Функция:** Анализ изображений "до/после" через Claude AI
- **Возможности:** Анализ фотографий для парикмахерских услуг

### 📚 **Хранение истории задач**

- **Код:** `src/entities/` + database management features
- **Функция:** Трекинг всех действий агентов и истории изменений
- **Возможности:** Store/get agent configs, task history, statistics

### ⚙️ **Конфигурация системы**

- **Код:** `src/config/` (ai-agent, jira, claude, database, redis, notifications)
- **Функция:** Централизованное управление настройками всех сервисов
- **Файлы:** 8 конфигурационных модулей

### 🏗️ **Модульная архитектура**

- **Принцип:** Каждый эндпоинт = отдельная папка в `src/features/`
- **Структура:** controller.ts + service.ts + dto.ts + module.ts + spec.ts
- **Соответствие:** Строгое следование инструкциям проекта

## 🔧 Технологический стек

- **Backend:** NestJS + TypeScript
- **База данных:** PostgreSQL + TypeORM
- **Кеширование:** Redis
- **Очереди:** Bull Queue + Redis
- **AI:** Claude AI (Anthropic) с многоуровневым анализом
- **Интеграция:** Jira REST API
- **Уведомления:** Email + Telegram Bot API
- **Пакетный менеджер:** Yarn (строго, никогда npm!)
