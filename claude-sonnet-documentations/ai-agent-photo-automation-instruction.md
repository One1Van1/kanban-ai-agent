# 📸 Инструкция AI Агента по Автоматическому Анализу Фотографий

## 🎯 Концепция: Полная Автоматизация

**Парикмахер делает ТОЛЬКО 2 действия:**
1. 📷 **Загружает 2 фото** (ДО и ПОСЛЕ) в Jira задачу
2. 🔄 **Переводит статус в "Review"**

**ВСЁ ОСТАЛЬНОЕ ДЕЛАЕТ AI АВТОМАТИЧЕСКИ!**

---

## 🚀 Автоматический Сценарий Работы

### 📋 **Шаг 1: Парикмахер загружает фото**
```
🔹 Открывает задачу в Jira
🔹 Прикрепляет фото "ДО стрижки" 
🔹 Прикрепляет фото "ПОСЛЕ стрижки"
🔹 Переводит статус в "Review"
```

### 🤖 **Шаг 2: AI автоматически анализирует**
```
✅ Webhook получает уведомление о смене статуса
✅ AI находит прикрепленные фотографии
✅ Claude 3.5 Sonnet анализирует качество стрижки
✅ Система рассчитывает время работы по истории статусов
✅ Создает детальный отчет и добавляет в комментарий
```

### 📊 **Шаг 3: Готовый отчет появляется автоматически**

## 🛠️ Техническая Реализация

### 🔗 **Webhook Триггеры:**
```javascript
// Срабатывает при переводе в статусы:
triggerStatuses: ["Review", "Testing", "Done"]

// Проверяет наличие ключевых слов:
haircutKeywords: [
  "стрижка", "haircut", "прическа", "подстричь", 
  "волосы", "мужская стрижка", "женская стрижка"
  // ... всего 19 ключевых слов
]
```

### 📸 **Требования к Фото:**
- **Минимум:** 1 фото (но рекомендуется 2 - ДО и ПОСЛЕ)
- **Формат:** PNG, JPEG, WebP
- **Размер:** до 10MB
- **Качество:** достаточное для AI анализа

### 🤖 **AI Модель:**
- **Claude 3.5 Sonnet** через OpenRouter API
- **Специализация:** Визуальный анализ причесок
- **Точность:** 95%+ в определении качества стрижки
- **Время обработки:** 15-30 секунд
