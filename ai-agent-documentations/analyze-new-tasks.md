# Analyze New Tasks API

## Описание

Эндпойнт для анализа задач в колонке "New" с помощью AI агента.

## Endpoint

```
POST /ai-agent/analyze-new-tasks
```

## Описание функциональности

AI агент анализирует все задачи в колонке "New" и автоматически перемещает их:

- **Понятные задачи** → В колонку "In Progress"
- **Непонятные задачи** → В колонку "Questions"

Агент использует алгоритмы машинного обучения для определения четкости и полноты описания задач.

## Параметры запроса

Не требуются (анализируются все задачи в колонке "New").

## Пример запроса

```bash
curl -X POST http://localhost:3000/ai-agent/analyze-new-tasks \
  -H "Content-Type: application/json"
```

## Ответы

### Успешный ответ (200)

```json
{
  "tasksAnalyzed": 3,
  "tasksMoved": 2,
  "results": [
    {
      "taskKey": "KAN-5",
      "decision": "move_to_progress",
      "reason": "Task is clear and well-defined",
      "moved": true
    },
    {
      "taskKey": "KAN-6",
      "decision": "move_to_questions",
      "reason": "Task description is unclear or incomplete",
      "moved": true
    },
    {
      "taskKey": "KAN-7",
      "decision": "keep_in_new",
      "reason": "Task is being processed by another service",
      "moved": false
    }
  ],
  "timestamp": "2025-09-23T15:04:11.000Z",
  "duration": 2340
}
```

### Структура ответа

| Поле          | Тип    | Описание                                     |
| ------------- | ------ | -------------------------------------------- |
| tasksAnalyzed | number | Общее количество проанализированных задач    |
| tasksMoved    | number | Количество перемещённых задач                |
| results       | array  | Массив результатов анализа для каждой задачи |
| timestamp     | string | Временная метка выполнения анализа           |
| duration      | number | Время выполнения в миллисекундах             |

### Структура объекта result

| Поле     | Тип     | Описание                  |
| -------- | ------- | ------------------------- |
| taskKey  | string  | Ключ задачи               |
| decision | string  | Решение AI агента         |
| reason   | string  | Причина принятого решения |
| moved    | boolean | Была ли задача перемещена |

### Возможные решения (decision)

- **move_to_progress** - Переместить в "In Progress"
- **move_to_questions** - Переместить в "Questions"
- **keep_in_new** - Оставить в "New"

## Возможные ошибки

- **500 Internal Server Error** - Ошибка при анализе задач или обращении к Jira API
- **503 Service Unavailable** - AI сервис недоступен

## Логика анализа

### Критерии для перемещения в "In Progress"

- Четкое и понятное название задачи
- Подробное описание с техническими требованиями
- Указаны acceptance criteria
- Задача не требует дополнительных уточнений

### Критерии для перемещения в "Questions"

- Неясное или слишком общее описание
- Отсутствуют технические детали
- Требуются дополнительные уточнения
- Противоречивые требования

### Технологии AI анализа

- **Natural Language Processing (NLP)** для анализа текста
- **Классификация задач** по уровню детализации
- **Sentiment Analysis** для определения тональности
- **Keywords Extraction** для поиска ключевых терминов

## Автоматизация

Этот эндпойнт может вызываться:

- По расписанию через cron jobs
- При создании новых задач через webhooks
- Вручную через API или веб-интерфейс
- В рамках автоматического workflow

## Мониторинг

- Все операции логируются с деталями решений
- Отслеживается точность предсказаний AI
- Ведется статистика по типам перемещений
- Сохраняется история анализов для обучения модели

## Примечания

- Анализ выполняется только для задач в статусе "New"
- Задачи с лейблами "no-ai" игнорируются
- При ошибке перемещения задача остается в исходной колонке
- Результаты анализа сохраняются для последующего обучения AI

## Настройка AI модели

Поведение агента можно настроить через переменные окружения:

- `AI_CONFIDENCE_THRESHOLD` - Пороговое значение уверенности (по умолчанию: 0.7)
- `AI_MODEL_VERSION` - Версия используемой модели
- `AI_ENABLE_LEARNING` - Включить обучение на новых данных
