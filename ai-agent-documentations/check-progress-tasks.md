# Check Progress Tasks API

## Описание

Эндпойнт для проверки задач в колонке "In Progress" с помощью AI агента.

## Endpoint

```
POST /ai-agent/check-progress-tasks
```

## Описание функциональности

AI агент проверяет все задачи в колонке "In Progress" и автоматически перемещает завершённые задачи в колонку "Review".

Агент анализирует:

- Комментарии разработчиков
- Время в работе
- Ключевые слова завершения
- Статус связанных подзадач

## Параметры запроса

Не требуются (проверяются все задачи в колонке "In Progress").

## Пример запроса

```bash
curl -X POST http://localhost:3000/ai-agent/check-progress-tasks \
  -H "Content-Type: application/json"
```

## Ответы

### Успешный ответ (200)

```json
{
  "tasksChecked": 4,
  "tasksMoved": 2,
  "results": [
    {
      "taskKey": "KAN-8",
      "decision": "move_to_review",
      "reason": "Task appears to be completed based on latest comments",
      "moved": true,
      "lastActivity": "2025-09-23T14:30:00.000Z"
    },
    {
      "taskKey": "KAN-9",
      "decision": "keep_in_progress",
      "reason": "Development is still ongoing",
      "moved": false,
      "lastActivity": "2025-09-23T15:00:00.000Z"
    },
    {
      "taskKey": "KAN-10",
      "decision": "move_to_review",
      "reason": "All acceptance criteria completed",
      "moved": true,
      "lastActivity": "2025-09-23T13:45:00.000Z"
    }
  ],
  "timestamp": "2025-09-23T15:04:11.000Z",
  "duration": 1870
}
```

### Структура ответа

| Поле         | Тип    | Описание                                      |
| ------------ | ------ | --------------------------------------------- |
| tasksChecked | number | Общее количество проверенных задач            |
| tasksMoved   | number | Количество перемещённых задач                 |
| results      | array  | Массив результатов проверки для каждой задачи |
| timestamp    | string | Временная метка выполнения проверки           |
| duration     | number | Время выполнения в миллисекундах              |

### Структура объекта result

| Поле         | Тип     | Описание                             |
| ------------ | ------- | ------------------------------------ |
| taskKey      | string  | Ключ задачи                          |
| decision     | string  | Решение AI агента                    |
| reason       | string  | Причина принятого решения            |
| moved        | boolean | Была ли задача перемещена            |
| lastActivity | string  | Время последней активности по задаче |

### Возможные решения (decision)

- **move_to_review** - Переместить в "Review"
- **keep_in_progress** - Оставить в "In Progress"
- **move_to_questions** - Переместить в "Questions" (если требуются уточнения)

## Возможные ошибки

- **500 Internal Server Error** - Ошибка при проверке задач или обращении к Jira API
- **503 Service Unavailable** - AI сервис недоступен

## Логика проверки

### Критерии для перемещения в "Review"

- Комментарии содержат ключевые слова завершения:
  - "готово", "завершено", "done", "completed"
  - "готов к ревью", "ready for review"
  - "все сделано", "finished"
- Все подзадачи закрыты
- Прошло достаточно времени для выполнения
- Отсутствуют активные вопросы

### Критерии для оставления в "In Progress"

- Активная разработка (недавние комментарии)
- Присутствуют слова "в процессе", "работаю над"
- Есть открытые блокеры или вопросы
- Задача недавно начата

### Критерии для перемещения в "Questions"

- Долгое время без активности (>3 дней)
- Комментарии указывают на проблемы или блокеры
- Требуются дополнительные требования

## Алгоритмы AI анализа

### Анализ комментариев

- **Sentiment Analysis** - определение настроения комментариев
- **Keywords Detection** - поиск ключевых слов завершения
- **Progress Tracking** - отслеживание прогресса по комментариям
- **Timeline Analysis** - анализ временных промежутков

### Анализ активности

- Частота обновлений задачи
- Время последнего комментария
- Количество связанных коммитов (если интегрировано с Git)
- Статус CI/CD пайплайнов

## Автоматические действия

### При перемещении в Review

AI агент автоматически:

- Добавляет комментарий о завершении
- Уведомляет ответственного за ревью
- Обновляет временные метки

### При выявлении проблем

- Добавляет комментарий с рекомендациями
- Может назначить задачу обратно автору
- Создает напоминания для проверки

## Конфигурация

### Временные пороги

```bash
# Максимальное время в In Progress (часы)
AI_MAX_PROGRESS_HOURS=72

# Минимальное время перед автопроверкой (часы)
AI_MIN_PROGRESS_HOURS=4

# Порог неактивности для перемещения в Questions (дни)
AI_INACTIVE_THRESHOLD_DAYS=3
```

### Ключевые слова завершения

Настраиваются через конфигурацию:

- Английские: "done", "completed", "finished", "ready"
- Русские: "готово", "завершено", "сделано", "готов"

## Интеграции

### Git Integration

При наличии интеграции с Git:

- Анализирует коммиты по задаче
- Проверяет статус pull requests
- Учитывает результаты тестов

### CI/CD Integration

- Проверяет статус билдов
- Анализирует результаты тестов
- Учитывает деплой статус

## Мониторинг и аналитика

- Точность предсказаний AI агента
- Статистика по времени выполнения задач
- Анализ эффективности команды
- Выявление узких мест в процессе

## Обучение модели

AI модель обучается на основе:

- Ручных корректировок решений
- Фактического времени выполнения задач
- Обратной связи от команды
- Исторических данных проекта

## Примечания

- Проверка выполняется только для задач в статусе "In Progress"
- Задачи с лейблом "manual-review" исключаются из автопроверки
- При неуверенности агент оставляет задачу без изменений
- Все решения логируются для анализа качества
