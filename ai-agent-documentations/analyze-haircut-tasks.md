# Analyze Haircut Tasks API

## Описание

Эндпойнт для анализа задач о парикмахерских услугах с помощью AI агента.

## Endpoint

```
POST /ai-agent/analyze-haircut-tasks
```

## Описание функциональности

AI агент специализированно анализирует задачи в колонке "New", связанные с парикмахерскими услугами (стрижки, окрашивания, укладки):

- **Полные задачи** (название + описание + фото) → перемещаются в "In Progress"
- **Неполные задачи** (только название) → перемещаются в "Questions" с комментарием

Агент проверяет наличие ключевых слов, связанных со стрижкой, и анализирует полноту информации.

## Параметры запроса

### Request Body

```json
{
  "includeImages": true,
  "commentTemplate": "Какую именно стрижку ты хочешь?",
  "strictMode": false
}
```

| Поле            | Тип     | Обязательный | Описание                              | По умолчанию                      |
| --------------- | ------- | ------------ | ------------------------------------- | --------------------------------- |
| includeImages   | boolean | Нет          | Требовать наличие изображений         | true                              |
| commentTemplate | string  | Нет          | Шаблон комментария для неполных задач | "Какую именно стрижку ты хочешь?" |
| strictMode      | boolean | Нет          | Строгий режим проверки                | false                             |

## Пример запроса

```bash
curl -X POST http://localhost:3000/ai-agent/analyze-haircut-tasks \
  -H "Content-Type: application/json" \
  -d '{
    "includeImages": true,
    "commentTemplate": "Пожалуйста, добавьте фото желаемой стрижки и детальное описание",
    "strictMode": false
  }'
```

### Анализ изображений

## Логика принятия решений

### Перемещение в "In Progress"

Задача перемещается в работу, если:

```javascript
const shouldMoveToProgress = (task) => {
  return (
    task.hasHaircutKeywords &&
    task.hasDescription &&
    (task.hasImage || !strictMode) &&
    task.confidence > 0.8
  );
};
```

### Перемещение в "Questions"

Задача перемещается в вопросы, если:

```javascript
const shouldMoveToQuestions = (task) => {
  return (
    task.hasHaircutKeywords &&
    (!task.hasDescription || (!task.hasImage && includeImages)) &&
    task.confidence > 0.6
  );
};
```

## Интеграция с календарём

### Автоматическое планирование

При перемещении задачи в "In Progress":

1. Оценка времени выполнения услуги
2. Проверка доступности мастера
3. Предложение временных слотов
4. Автоматическое бронирование (опционально)

### Уведомления мастерам

- SMS о новой записи
- Email с деталями услуги
- Push в мобильное приложение
- Календарные события
